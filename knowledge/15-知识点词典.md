## 三、组合名展开表（归一用）

一个「组合名」= 一次拆成**多个**标准名（区别于别名：别名是一对一改名）。
拆开后按原位置依次放入，外面可照常套 `[]` 与标注。

| 组合名 | 展开为 |
|---|---|
| 前缀和与差分 | 前缀和 + 差分 |

「前缀和与差分」不再是一个标准名（前缀和、差分是两个知识点）；要表达"两者常一起出现"，写 `[前缀和 + 差分]`。

## 五、写法规则（给人看）

- **知识点写法（v2，2026-10-05 用户选定）**——一套符号、四层语义：

  | 符号 | 含义 |
  |---|---|
  | `；` | **解法分隔**：正解排最前，其余是另解（同一解法的两种等价实现也这样并列） |
  | ` + ` | 同一解法内**并列使用**的知识点 |
  | `[…]` | **打包**成一组（同时出现的一小组）；可嵌套 |
  | `[主]` / `[次]` | **主次标注**，可省略：并列关系不标，有主次才标（至少标出主） |

  示例（从简到繁）：
  - `素数`
  - `前缀和 + 差分 + 排序 + 枚举`
  - `[前缀和 + 差分][主] + 排序 + 枚举`
  - `二分图匹配[主] + Hall 定理 ； 枚举 ； DFS`
  - `二分查找[主] + [前缀和 + 差分][次] ； 树状数组 ； 线段树[主] + 二分查找[次]`

  旧格式「主 ｜ 次1、次2」2026-10-05 废止；迁移映射 = 竖线左边那一段加 `[主]`，右边各段原样进 `+` 串。
- **两个不同的解法之间只能写 `；`，不许拿空格并排**（2026-10-05 用户拍板）：空格不是规范符号——
  两个名字并排 = 两个解法 = 必须用 `；` 分组；两组共用的泛用知识点（如「连通块计数」）跟正解那一组，
  不重复写第二遍。已改：Round 161 D `DFS BFS[主] + 连通块计数` → `BFS[主] + 连通块计数 ； DFS`
  （这题参考代码用的是队列 BFS，递归 DFS 是另解）；`DFS BFS` 不再是标准名，需要时分别写 `DFS` / `BFS`。
- **括号说明一律删**：「位运算（末尾零计数）」→「位运算」——细节留在题解正文，不进标准名。
- **落地位置**：同一道题的标准串在**三处逐字一致**——记录 md 头部「数据结构与算法」、状态表「知识点」列、题解 md 目录表「**考点**」列（前两处机器归一口径 = 本文件；第三处由 `check_solution.py` **第 18 项**把关）。题解正文照常写 LaTeX，但这三列都是**数据字段、不写 `$`**（`unify_latex` 已豁免目录表，不会把 `DP[主]` 转成 `$DP$[主]`）。
- **自动归一流程**（新场次走这条）：按顶层 `；`（半角 `;` 也认）分解法组 → 组内按顶层 `+` / `、`
  拆项（顿号视同 `+`）→ 剥掉尾部 `[主]` / `[次]` 标注（`(主)`、`（主）` 也认）→ 去括号 →
  别名映射 → 命中删除表就删 → **组合名展开**（查本文件第三节）→ **修饰兜底** →
  首字母缩写大写（`dfs` → `DFS`）→ 按原结构重新拼装（组间 ` ； `、组内 ` + `、`[…]` 与标注原样保留）。
  修饰兜底（2026-10-05 加）：段以某个已登记名字**开头或结尾**、且还剩修饰字 → 归到它
  ——「分组前缀和」→「前缀和」、「枚举一维」→「枚举」、「迭代 DFS」→「DFS」；
  候选按长度降序（最长优先）；删除表**先于**兜底判定（「DFS 枚举因子」整段删，不会被吃成「DFS」）。
- **未登记名字的处理**：能自动映射（含修饰兜底）就映射，兜底命中会进报告供核对；
  映射不了会**被拦**——写状态表（`fill_knowledge.py`）与归档对账（`archive_check.py`）
  都把未登记段报出来（退出码非 0），逼着收编进本文件（收为别名 / 立新标准名）或改写法；
  确实写错就打回。落盘时未登记段**原样保留**，不会静默丢。
- **文件夹同口径**：manifest 的 `folder` 从「归档文件夹」列挑；挑不到也照收（报告里列为未登记文件夹），
  但不猜——落盘时名字原样保留，等维护者收编。

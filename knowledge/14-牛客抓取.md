# 牛客抓取（ac.nowcoder.com）

> 类型：方法 ｜ 抓题面 / 题单的可行路径与配方；仓库工具 `tools/fetch_problem.py`
> 就是按本文实现的（用法见《工具链》）。

## 关键结论

- **直取页面是主通道**：部分环境的网页抓取工具对 `ac.nowcoder.com` 会报
  "Unable to verify if domain is safe to fetch" 之类的拦截 —— 改用 `curl` 直取 HTML 即可。
- **独立题目页的题面是服务端渲染的，就藏在 HTML 里**：不需要 JS、不需要登录、不需要 API。

```
curl -sL -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36" \
  "https://ac.nowcoder.com/acm/problem/<题号>" -o p.html
```

- 比赛题目页 `https://ac.nowcoder.com/acm/contest/<cid>/<题目字母>`（如 `/D`）
  **就是服务端渲染的完整题面**：一次 curl 就能拿到题面 + 输入输出 + 样例 + 样例说明，
  比反查 `/acm/problem/<id>` 省事得多。在 HTML 里找 `class="subject-description"` /
  `题目描述` 区块。

## 公式怎么取

公式长这样：

```html
<img src="/acm/equation?tex=%5Csum" alt="latex">
```

**真 LaTeX 在 `src` 的 `?tex=` 参数里（URL 编码），`alt` 只是占位符字符串 `latex`。**
**别按 `alt` 取**：按它取会得到满屏 `$latex$`。还原写法：

    parse_qs(urlparse(src).query)['tex'][0]   # 再 unquote

`alt` 只能当兜底，且要先判掉 `alt == 'latex'`。另需过滤牛客排版的 `\hspace{15pt}` 填充。

## 剥正文的配方

1. 先 `<img ... src="...?tex=Y" ...>` → `$Y$`（**从 `src` 取，不是 `alt`**）；
2. 删 script / style；
3. 把 `<br>`、`</p|div|li|td|tr|pre>` 换成换行；
4. 剥标签 + `html.unescape`。

注意：页面里每个样例会出现两遍（源码区 + "复制"区），提取结果要人工看一眼去重。

## 题单接口

`https://ac.nowcoder.com/acm/contest/problem-list?token=&id=<cid>` 直接返回 JSON，
无需登录；`data.data[]` 里每题有 `index`（A/B/C…）、`title`、`problemId`、
`submitCount` / `acceptedCount`。

**先用它把题目数数清** —— 默认要求是「写全部题目」，先知道是 A~F 还是 A~L，免得漏题；
顺带能从通过数看出哪题最毒（通过数断崖式低的题要重点防挂）。比赛主页 HTML 是 JS 壳、
拿不到题单，但 `<title>` 里有比赛名。

## 其它入口

- 比赛主页是 JS 壳，但 `<title>` 能拿到题名；用题名去网页搜索，可以反查到独立题号
  `/acm/problem/<id>`，再去取正文。
- 题解：搜索「牛客周赛 Round <N> 题解」；`blog.nowcoder.net/n/<hash>` 的博客页
  可以直接 curl 下来，按 `</p>|</div>|</li>|<br>` 换行再剥标签就能读
  （公式同样会丢，看思路够用）。
- 搜索结果的快照可能过期（摘要写"报名中"，实际题目页已可访问）—— 以直取页面的结果为准。

## 纪律

**比赛进行中不要抓题面求助。** 这套流程只在比赛结束后用于归档 / 写题解。

# 牛客周赛 Round 163 D - 小月的地砖

- **难度**：CF 1300
- **原题链接**：https://ac.nowcoder.com/acm/contest/140737/D
- **题解位置**：`<数据根>\题解\牛客周赛\Round163\Round163题解.md`（整场题解，含完整推导）
- **归档文件夹**：`构造\`
- **数据结构与算法**：构造
- **具体知识点**：把 1 排成一条一维长带子，再对列数取模铺满；三条约束一次性自动满足

## 题意（精简）

要构造一个 n 行 m 列的 01 网格，满足三条：第 i 行恰好有 a<sub>i</sub> 个 1；每行的 1 在环上连续（第 m 列与第 1 列相邻，允许跨边界连成一段）；任意两列中 1 的个数之差不超过 1。
输出任意一个合法解（Special Judge）。

**数据范围**：n, m ≤ 2×10^5，且 n×m ≤ 2×10^5

## 关键点（为什么用这个算法）

1. 条件 3 已经把答案卡得很死：1 的总数 S = a<sub>1</sub> + … + a<sub>n</sub>，平均到 m 列是 S/m，所以每列的 1 的个数只能是 ⌊S/m⌋ 或 ⌈S/m⌉——"每列分到几个"是唯一确定的。
2. 朴素的一行一行手工填（从上一行结束的列继续往后放 a<sub>i</sub> 个连续 1）其实就是正解的手工版，但起点一旦算错，某列就会多一个少一个，需要一个精确模型兜底。
3. 正解模型：把所有 1 排成一条编号 0 … S−1 的一维长带子，第 i 行占 [P<sub>i</sub>, P<sub>i</sub> + a<sub>i</sub>)（P<sub>i</sub> 是前 i−1 行 1 的个数和），带子上第 t 个位置映射到列 t mod m。于是每行个数正好是 a<sub>i</sub>；映射后仍是环上连续的一段（可能跨过 m−1 → 0）；第 j 列拿到的正是带子上模 m 余 j 的那些位置，个数只能是 ⌊S/m⌋ 或 ⌈S/m⌉。三条约束全部自动成立。

## 复杂度

- 时间：O(n + S) = O(nm)（每个 1 只摆放一次），nm ≤ 2×10^5
- 空间：O(nm) 存输出网格（n 个字符串）

## 踩过的坑

1. 以为"环上连续"必须挤成一段 → 1001 在 m = 4 时完全合法（列 3 与列 0 相邻），不要为了"看起来连续"把 1 挪到一起。
2. a<sub>i</sub> = 0 或 a<sub>i</sub> = m 不会处理 → 长带子模型天然支持：空段长度为 0，a<sub>i</sub> = m 时正好覆盖所有列、整行全 1。
3. 拿牛客"自测运行"的报错当自己的错 → 本题是 Special Judge，自测可能只比对一份标准答案，报错是正常的，要按三条约束自己检查。
4. 用 `endl` 逐行刷新输出 → 输出量 n×m ≤ 2×10^5 字符，用 `puts` 或 `'\n'` 就好。

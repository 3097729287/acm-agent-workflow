## 五、写法规则（给人看）

- **知识点写法（v2，2026-10-05 用户选定；2026-10-06 修订：`；` 解法分隔废止）**——一套符号、三层语义：

  | 符号 | 含义 |
  |---|---|
  | ` + ` | 同一条解法里**并列使用**的知识点 |
  | `[…]` | **打包**成一组（同时出现的一小组）；可嵌套 |
  | `[主]` / `[次]` | **主次标注**，可省略：并列关系不标，有主次才标（至少标出主）。**只有一个知识点时不标** —— 没有「次」可对，标了是冗余（2026-10-05 用户纠正：周赛 142 E 曾写成 `结论与计数[主]`，已改回 `结论与计数`） |

  示例（从简到繁）：
  - `素数`
  - `前缀和 + 差分 + 排序 + 枚举`
  - `[前缀和 + 差分][主] + 排序 + 枚举`
  - `组合计数[主] + DFS`

  已废止的两个符号：旧格式「主 ｜ 次1、次2」2026-10-05 废止（迁移映射 = 竖线左边那一段加 `[主]`，
  右边各段原样进 `+` 串）；**`；` 解法分隔 2026-10-06 废止**（只写题解实际使用的那条解法，见下面「一题只写一条解法」）。

- **`[主]` 的判据 = 「换个等价工具，解法还成不成立」**（2026-10-05 用户追问「F 题为什么 DFS 不是主」后定死，
  别按"谁先出现在代码里""谁名字更像题名"来定）：
  - 换成同类等价做法后**解法照样成立** → 它是**次**（工具 / 基础设施）；
  - **换不掉**（换掉就没有这条解法了）→ 它是**主**（这道题真正考的东西）；
  - 同一层里彼此都换不掉的几个环节（`前缀和 + 差分 + 排序 + 枚举`）→ **并列，不标**。

  两个已拍板的例：周赛 142 F 的遍历从 `DFS` 换成 `BFS`，解法一个字都不用改（都要"定根 + 后序求子树最大值"）
  → `DFS` 是次、`组合计数` 是主，写 `组合计数[主] + DFS`；周赛 123 G 的 `排序` 换成桶 / 离散化仍要 `双指针`
  那一套 → `双指针[主] + 排序`。反过来，周赛 142 E 全题只有一个知识点（`结论与计数`），无主次可标。

- **一题只写一条解法 = 题解实际使用的那条**（2026-10-06 用户拍板，**取代** 2026-10-05 的
  「`；` 列另解、DFS / BFS 两种思想都要补上」）：知识点串只写**参考代码所用的做法**那一条链；
  题解正文里提到的其它思路 / 等价写法（「把 BFS 换成 DFS 同样可行」「另有全排列枚举的等价写法」）
  **留在正文，不进这一列**。已按此清理（2026-10-06，四题）：
  - 周赛 142 F：`组合计数[主] + DFS`（弃 `； 组合计数[主] + BFS`）
  - 周赛 156 E：`BFS`（弃 `； DFS`）
  - 周赛 161 D：`BFS[主] + 连通块计数`（弃 `； DFS[主] + 连通块计数`）
  - 周赛 163 C：`二分图匹配[主] + Hall 定理`（弃 `； 枚举 ； DFS`）

  **斜杠不是本格式的符号**：`DFS/BFS` 会被修饰兜底吃成单个 `DFS`（实测 `mapped=[('DFS/BFS','DFS')]`，
  BFS 静默丢失）；空格同样不是 —— `DFS BFS` 会被吃成单个 `DFS`。名字需要几个写几个，各写各的。
- **`排序` / `快速幂` / `栈` / `二分查找` 这类是「标准化的单一概念」**：快排 / 归并 / 桶排都是 `排序`
  这一个标准名的内部实现，**不拆开写**（2026-10-05 定，继续有效）。
- 边界：知识点只收**这条解法真正用到的技术**；只用来对拍的暴力、复杂度不达标的写法**不算**，不进这一列。
- **`博弈论`（2026-10-07 新增，专题级）的判据**：题面是**双方对抗**（轮流操作 / 一方策略 vs 另一方）+ 解题的关键 insight 是**对双方最优行为的分析**（必胜必败判定、策略对偶）→ 标 `博弈论`。
  不标的三种：① 只是叙事性的"游戏"，实质是确定性模拟（Div.3 1084 A Eating Game）；② 单方决策、对手没有动作（练习赛 153 C「博弈」实为最大子段和）；③ 对抗只是外壳、核心是别的算法（周赛 163 C 小月的对局 → `二分图匹配[主] + Hall 定理`）。
  2026-10-07 首轮收编 15 题（ARC 225 B / Div.2 1113 A、1116 C、1117 B、1120 A / Div.3 1084 E、1103 D、1122 B / 小白月赛 133 B、134 B、135 D / 练习赛 155 B、156 B、157 A / 周赛 146 E），其中 `贪心`、`DP` 混装的各 2、1 题一并改正。

- **括号说明一律删**：「位运算（末尾零计数）」→「位运算」——细节留在题解正文，不进标准名。
- **落地位置**：同一道题的标准串在**三处逐字一致**——记录 md 头部「数据结构与算法」、状态表「知识点」列、题解 md 目录表「**考点**」列（前两处机器归一口径 = 本文件；第三处由 `check_solution.py` **第 18 项**把关）。题解正文照常写 LaTeX，但这三列都是**数据字段、不写 `$`**（`unify_latex` 已豁免目录表，不会把 `线性 DP[主]` 转成 `$线性 DP$[主]`）。
- **自动归一流程**（新场次走这条）：按顶层 `；`（半角 `;` 也认；**历史格式——解析仍宽容、写法已废止**，
  归一结果里再出现 `；` 会被闸门报出来：`check_solution` 第 18 项 / `tb_sync` 收工对账 / 写状态表）分解法组 →
  组内按顶层 `+` / `、` 拆项（顿号视同 `+`）→ 剥掉尾部 `[主]` / `[次]` 标注（`(主)`、`（主）` 也认）→ 去括号 →
  别名映射 → 命中删除表就删 → **组合名展开**（查本文件第三节）→ **修饰兜底** →
  首字母缩写大写（`dfs` → `DFS`）→ 按原结构重新拼装（组内 ` + `、`[…]` 与标注原样保留）。
  修饰兜底（2026-10-05 加）：段以某个已登记名字**开头或结尾**、且还剩修饰字 → 归到它
  ——「分组前缀和」→「前缀和」、「枚举一维」→「枚举」、「迭代 DFS」→「DFS」；
  候选按长度降序（最长优先）；删除表**先于**兜底判定（「DFS 枚举因子」整段删，不会被吃成「DFS」）。
- **未登记名字的处理**：能自动映射（含修饰兜底）就映射，兜底命中会进报告供核对；
  映射不了会**被拦**——写状态表（`fill_knowledge.py`）与收工对账（`tb_sync.py`）
  都把未登记段报出来（退出码非 0），逼着收编进本文件（收为别名 / 立新标准名）或改写法；
  确实写错就打回。落盘时未登记段**原样保留**，不会静默丢。
- **文件夹同口径**：manifest 的 `folder` 从「归档文件夹」列挑；挑不到也照收（报告里列为未登记文件夹），
  但不猜——落盘时名字原样保留，等维护者收编。

## 六、父子关系表（统计页折叠用；v17，2026-10-08 放宽为多级）

**只影响「知识点统计」页的显示分组，不改任何知识点本身的写法**：父行显示**子孙次数合计**，
对父行按 `Enter` 展开 / 收起子行；子行只在展开后出现、**不再单独计入顶层统计**。

规则：
- **父**是**分桶标签**，不必是标准名（如 `计数`、`数据结构`、`搜索`、`二分`、`前缀和与差分` 都是新造的桶名）；

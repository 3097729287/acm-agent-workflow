# status_gui 布局说明（部位标准叫法）

用途：**给 status_gui 图形端提界面需求时，按这里的部位名说就行**（如「把第一行的搜索框加宽」），
不用截图圈位置。每个窗口都配 ASCII 示意图，尺寸与相对位置照着 `tools/status_gui.py` 的实际布局画。

## 一、主窗口
```
┌──────────────────────────────────────────────────────────────┐
│ 题目状态跟踪表                                        —  □  × │ ← 标题栏（系统画的，改不了）
├──────────────────────────────────────────────────────────────┤
│ 题解包 ▾                                                      │ ← 菜单栏
├──────────────────────────────────────────────────────────────┤
│ 搜　索 [ 场次 / 题名 / 知识点 / 难度 ]  共 N 题 ｜ …  ｜ 消息  │ ← 第一行
│ ┌ 筛选面板（搜索框里按 ↓ 展开）─────────────────────────────┐ │
│ │ 知识点 [ 如 DP、二分 ]                                    │ │
│ │ 难　度 [ 如 1700-1900 ]                                   │ │
│ │ 状　态 ┌ 1. 未做 … ┐                        筛出 N 题     │ │
│ │        └───────────┘                                      │ │
│ └───────────────────────────────────────────────────────────┘ │
│ ┌ 总表（表格区）────────────────────────────────────────────┐ │
│ │ 场次 ▲｜题号｜题名｜知识点｜难度｜状态｜日期                  │ │ ← 表头
│ │ 牛客周赛 Round 123｜C｜小红出对｜构造｜CF 1300｜未做｜日期    │ │ ← 数据行
│ │                                                    ▐ 滚动条│ │
│ └───────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```
### 部位名对照（主窗口）

| 部位名 | 位置 / 说明 |
|---|---|
| 标题栏 / 菜单栏 | 最顶上是标题栏「题目状态跟踪表」+ 最小化 / 最大化 / 关闭（系统画的，动不了）；菜单栏在它下面，只有「题解包」：导入题解包… / 导出题解包… / 一键校验… |
| **第一行** | 菜单栏下面那条，整条从左到右：**搜索标签**（`搜　索`）→ **搜索框** → **统计行**（共 N 题 ｜ 各状态计数 ｜ N 天内做对）→ 靠右端 **「筛出 N 题」小标**（筛选收起时挂这儿）+ **消息**（最右端，3 秒自动消失）；**筛选面板**在搜索框正下方，按 `↓` 展开，见放大图 |
| **表格区 / 总表** | 下半部分：表头 7 列（场次 / 题号 / 题名 / 知识点 / 难度 / 状态 / 日期）+ 数据行 + 右缘滚动条；点「场次 / 难度 / 日期」表头 = 排序。数据行一行一题，选中行蓝底、按 `1`~`6` 直接改状态 |
### 筛选面板（放大）
```
┌──────────────────────────────────────────────────────┐
│ 知识点 [ 如 DP、二分       ]                          │ ← 知识点行（标签 + 知识点框）
│ 难　度 [ 如 1700-1900      ]                          │ ← 难度行（标签 + 难度框）
│ 状　态 ┌ 1. 未做 ┐                      筛出 N 题      │ ← 状态行（标签 + 状态清单）
│        │ …      │                                    │
│        └────────┘                                    │
│                                                      │ ← 底排（只放「筛出 N 题」，右端）
└──────────────────────────────────────────────────────┘
```
- 知识点行 / 难度行：「知识点」「难度」标签 + 各自输入框；知识点逗号分隔多个词 = 并集，难度如 `1700-1900`、`<=1500`
- 状态清单：六个状态的勾选列表（空格 / Enter / `1`~`6` 勾选，可多选）
- 底排：面板最下面一行，右端「筛出 N 题」；清条件走 `Esc` 逐层退回

### 看板页（「今天要做的」，按 `←` / `→` 切过去）
```
┌  ① 待重写   ┐ ┌  ② 待补题   ┐ ┌  ③ D+7 复习  ┐ ┌  ④ D+30 抽检 ┐   ← 卡片区（4 张卡）
│     3       │ │     2       │ │     1        │ │     0       │
└─────────────┘ └─────────────┘ └──────────────┘ └──────────────┘
┌ 当前段的题清单（表格）─────────────────────────────────────────┐   ← 段清单
│ 场次 ｜ 题号 ｜ 题名 ｜ 知识点 ｜ 难度 ｜ 日期                    │
└──────────────────────────────────────────────────────────────┘
```
- 卡片区：四张数字卡（① 待重写 / ② 待补题 / ③ D+7 复习 / ④ D+30 抽检）；段清单：下方明细表（列同总表，但没有「状态」列）

**怎么进、怎么换**：`←` / `→` 在「总表 → ① → ② → ③ → ④」共 5 格上左右走、**两头绕回**——总表按 `→` 进第 ① 段、按 `←` 直接进第 ④ 段；第 ① 段按 `←` 回总表、第 ④ 段按 `→` 回总表。（换段用方向键，不是数字键；每段各自记住上次选中的行）

## 二、题解包三个弹窗

菜单位置：**菜单栏 → 题解包**。下面这三个窗口以后就叫「选包窗 / 导出窗 / 报告窗」。

### 1. 选包窗（点「导入题解包…」或「一键校验…」先弹它）
```
┌ 选择题解包 ────────────────────────────── ×┐   ← 窗口标题（窗内没有标题字）
│ 题解包（.zip 或解压后的目录）：              │   ← 说明标签
│ [                                        ] │   ← 路径框（空着时框内有灰字「包路径」）
│ [选 zip…] [选目录…]     [取消] [开始]       │   ← 按钮行（四个按钮并成一行）
└────────────────────────────────────────────┘
```
- 说明标签 / 路径框：「题解包（.zip 或解压后的目录）：」一行字；路径框可粘贴路径，没填时显示灰字提示「包路径」
- 选 zip… / 选目录…：两个选择按钮，靠按钮行左端
- 按钮行 / 主按钮「开始」：四个按钮并成一行，选择按钮在左、「取消 / 开始」在右，中间留空隙；「开始」蓝底白字、在按钮行最右端，路径没填时变浅灰点不动（填了才亮）

### 2. 导出窗（点「导出题解包…」弹它）
```
┌ 导出题解包 ─────────────────────────── ×┐
│ 场次 [牛客周赛 Round 163 ▾] 题号（空 = 整场）[  ] │   ← 第一行：场次 + 题号
│ 输出 zip [ <数据根>\牛客周赛Round163.zip ] [另存为…] │   ← 第二行：输出路径 + 另存为（同一行）
│                              [取消] [开始导出]  │   ← 弹窗底排（「开始导出」= 蓝底主按钮）
└──────────────────────────────────────────────┘
```
- 第一行：「场次」下拉（列出所有牛客周赛场次）+「题号（空 = 整场）」小输入框
- 输出行 / 另存为…：「输出 zip」长框（默认桌面）+ 它右端同一行的「另存为…」
- 弹窗底排 / 主按钮「开始导出」：右端「开始导出」蓝底白字 + 它左边「取消」

### 3. 报告窗（校验 / 导入 / 导出跑完都在它里面出报告）
```
┌ 题解包 —— 导入题解包 ─────────────── ×┐   ← 窗口标题
│ 包：牛客周赛Round163.zip               │   ← 副标题（这份报告是给哪个包的，灰字）
│ ┌───────────────────────────────────┐  │
│ │（等宽字报告正文，边跑边刷）          │  │   ← 报告区
│ └───────────────────────────────────┘  │
│ 校验通过 —— 可以应用到数据根            │   ← 状态行（跑着蓝字 / 通过绿字 / 失败红字）
│                  [应用到数据根] [关闭]   │   ← 弹窗底排
└───────────────────────────────────────┘
```
- 副标题 / 报告区：「包：xxx.zip」或「导出 … → …」（灰字）；报告区是等宽字体滚动区，跑的时候实时出内容
- 状态行：一句话结论；颜色 = 跑着**蓝**、通过**绿**、失败**红**
- 主按钮「应用到数据根」/ 弹窗底排：主按钮蓝底白字，没跑完时浅灰点不动（只在导入且校验通过后可点）；底排 = 主按钮 +「关闭」

## 三、两个小浮层

- 状态浮层（表格里按 `Enter`）：六状态选项框（↑↓ 选 / `1`~`6` 直选 / `Enter` 确认 / `Esc` 取消）
- 快捷键一览（按 `?`，Shift+/）：键位表（内容 = 手册里的键位表，逐字一致）

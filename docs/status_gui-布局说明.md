# status_gui 布局说明（部位标准叫法）

用途：**给 status_gui 图形端提界面需求时，按这里的部位名说就行**（如「把第一行的搜索框加宽」），
不用截图圈位置。每个窗口都配 ASCII 示意图（照 `tools/status_gui.py` 的实际布局画）。

> **v22（2026-10-05）更新**：三张表的**列与列之间多了 1px 浅灰蓝竖线**（`#c8d2e2`，列宽仍随窗伸缩）；**行着色**两套 —— 日期=今天 → 整行淡绿底、状态=不会/待重写 → 红字（可同时出现）。下面主窗口示意图里的 `｜` 就是这些竖线。
>
> **v21（2026-10-05）更新**：**菜单「一键校验…」整项删除**（题解包菜单只剩导入 / 导出两项）；**选包窗砍到最小** —— 只剩 `选择 zip…` + `开始` 两个按钮、`Esc` 取消，**路径输入框连同 `选目录…` / `取消` 一起删了**（见第二节）。键位也有重排（`S` / `R` 换成 `Ctrl+←`/`Ctrl+→` 换排序字段、`Ctrl+↑`/`Ctrl+↓` 反转升降序；搜索框里 `↑`/`↓` = 进主表）—— 键位详见使用说明。
>
> **v18（2026-10-05）更新**：**筛选面板整块拆除**（搜索框里按 `↓` 不再展开任何东西）—— 主窗口从「第一行 + 面板 + 表格」变回「第一行 + 表格」；筛选并进搜索框（六字段任一命中）。下面的主窗口示意图**已按 v18 重画**。
>
> **v17（2026-10-05）更新**：新增第三个页面「**统计页**（知识点统计）」（见下文新增小节）—— 切页横排从 5 格变 6 格。

### 列间竖线与行着色（v22）

| 部位 | 说明 |
|---|---|
| **列间竖线** | 总表 / 看板清单 / 统计清单三张表的**每两列之间**一条 **1px 浅灰蓝线**（`#c8d2e2`）；列宽仍**等比铺满、随窗伸缩**（拉宽窗口竖线跟着列边界挪）；**最后一条不画** |
| **行着色（两套，可同一行并存）** | ① **日期 = 今天** → 整行**淡绿底**（`#d8f0dc`）；② **状态 = 不会 / 待重写** → **红字**（`#c0392b`）。选中行按选中蓝盖过底色，字色照旧 |

### 部位名对照（主窗口）

| 部位名 | 位置 / 说明 |
|---|---|
| 标题栏 / 菜单栏 | 最顶上是标题栏「题目状态跟踪表」+ 最小化 / 最大化 / 关闭（系统画的，动不了）；菜单栏在它下面，只有「题解包」：导入题解包… / 导出题解包…（**v21 起只有这两项，「一键校验…」已删**） |
| **第一行** | 菜单栏下面那条，整条从左到右：**搜索标签**（`搜　索`）→ **搜索框** → **统计行**（共 N 题 ｜ 各状态计数 ｜ N 天内做对）→ 靠右端 **「筛出 N 题」小标**（搜索框有词时才挂这儿）+ **消息**（最右端，3 秒自动消失）；**v18 起下面直接就是表格区**（筛选面板已拆） |
| **表格区 / 总表** | 下半部分：表头 7 列（场次 / 题号 / 题名 / 知识点 / 难度 / 状态 / 日期）+ 数据行 + 右缘滚动条；点「场次 / 难度 / 日期」表头 = 排序。数据行一行一题，选中行蓝底、按 `1`~`6` 直接改状态；**列与列之间有一条 1px 浅灰蓝竖线**（v22；列宽照旧随窗伸缩、最后一条不画）、**日期=今天的行整行淡绿底 / 状态=不会·待重写的行红字**（v22，可同时出现） |

### 搜索框（放大）
```
┌──────────────────────────────────────────────────────┐
│ 搜　索 [ 如 123 E 连续 1300 未做       ]              │ ← 搜索标签 + 搜索框（灰字 = 占位提示）
└──────────────────────────────────────────────────────┘
```
- 一个框搜六列：**场次 / 题号 / 题名 / 知识点 / 难度 / 状态** —— 空格分隔多个词、每个词任一字段命中即算（词序随意）
- 框空着且没焦点时浮着浅灰提示 `如 123 E 连续 1300 未做`（统计页上换成 `知识点名`）；聚焦或打字即隐
- （v14~v17 的筛选面板 —— 知识点框 / 难度框 / 状态清单 / `↓` 展开 —— v18 整块拆除）

### 看板页（「今天要做的」，按 `←` / `→` 切过去）
```
┌  ① 待重写   ┐ ┌  ② 待补题   ┐ ┌  ③ D+7 复习  ┐ ┌  ④ D+30 抽检 ┐   ← 卡片区（4 张卡）
│     3       │ │     2       │ │     1        │ │     0       │
└─────────────┘ └─────────────┘ └──────────────┘ └──────────────┘
┌ 当前段的题清单（表格）─────────────────────────────────────────┐   ← 段清单
│ 场次 ｜ 题号 ｜ 题名 ｜ 知识点 ｜ 难度 ｜ 日期                    │
└──────────────────────────────────────────────────────────────┘
```
- 卡片区：四张数字卡（① 待重写 / ② 待补题 / ③ D+7 复习 / ④ D+30 抽检）；段清单：下方明细表（列同总表，但没有「状态」列）

**怎么进、怎么换**：`←` / `→` 在「总表 → 统计 → ① → ② → ③ → ④」共 6 格上左右走、**两头绕回**（v17 加了「统计」一格，见下节）——总表按 `→` 进统计页、按 `←` 直接进第 ④ 段；统计页按 `←` 回总表、按 `→` 进第 ① 段；第 ① 段按 `←` 回统计页、第 ④ 段按 `→` 回总表。（换段用方向键，不是数字键；每段各自记住上次选中的行）

### 统计页（「知识点统计」，按 `←` / `→` 切过去）（v17）
```
┌ 共 N 个知识点 ｜ M 题 ｜ 点列头或 Ctrl+方向键 换序 ｜ Enter 展开 / 搜索 ┐  ← 小字
┌ 知识点统计（表格）──────────────────────────────────────────┐
│ 知识点                                    ｜  次数 ▼         │  ← 表头（点「次数」排序）
│ ▸ 计数                                    ｜   32            │  ← 父行（收着，次数=子孙合计）
│   构造                                    ｜   19            │  ← 平铺知识点行
│ ▾ DP                                      ｜   15            │  ← 父行（展开中）
│     DP                                    ｜    9            │  ← 子行（缩进）
│     区间 DP                               ｜    1            │
└────────────────────────────────────────────────────────────┘
```
- 小字行：页面最上面一行灰字，汇总「共 N 个知识点 / M 题」+ 提示怎么排序 / 展开；搜索时变「筛出 N / 共 M 个知识点 ｜ 搜索只筛本页 ｜ …」
- 知识清单：两列（知识点 / 次数）；次数 = 拆到最细的各计一次（一题里重复写算多次）
- **父子折叠**：同类知识点折到父下 —— 父行行首 `▸`（收着）/ `▾`（展开），次数 = **子孙合计**；子行缩进 + **淡蓝底**（`C_ACCENT_LIGHT`）、**不再单独计入顶层**。分组表 = 词典 `15-知识点词典.md` 最末「父子关系表」
- **搜索**：顶上那个**主搜索框**（第一行）在统计页时搜的是**知识点名**（只筛本页清单），在总表时搜的是**题** —— 同一个框按页切语义、切页词不清；统计页的灰字提示也换成 `知识点名`
- 排序：默认**降序**（考得最多的在上），`Ctrl+方向键` 或点「次数」列头翻转；**换序时选中行钉在原行号**（行里的知识点换掉，选中位置不动）
- 选中一行按 `Enter` / 双击：**父行 = 展开 / 收起**；**叶行 / 子行 = 跳回总表页、搜索框填上这个知识点**（看清单一览）；跳过去后只要搜索框里**还含这个知识点名**（追加别的字段也行）按 `Esc` → 原路退回统计页、展开父行、选中原来那行；名字被改了才只清词
- **行上 `Esc`（v18）**：光标在**展开的父行 / 它下面的子行**上 → **收起该父行、光标移到父行**；没展开的行照旧走「清搜索 / 原路退回」那套

## 二、题解包三个弹窗

菜单位置：**菜单栏 → 题解包**。下面这三个窗口以后就叫「选包窗 / 导出窗 / 报告窗」。

### 1. 选包窗（点「导入题解包…」先弹它；v21 精简版）

```
┌ 选择题解包 ────────────────────── ×┐   ← 窗口标题（窗内没有标题字）
│ [还没选题解包……]                   │   ← 状态行（未选 = 灰字提示；选中 = 「已选：<文件名>」）
│ [选择 zip…]              [开始]     │   ← 按钮行（v21 起只剩两个按钮）
└────────────────────────────────────┘
```
- **v21 起这个窗只剩两个按钮**（路径输入框、`选目录…`、`取消` 三样全删）：**`选择 zip…`** 靠左、主按钮 **`开始`** 靠右
- 状态行：没选包时是一行灰字（如「还没选题解包……」）；选到包后变成「已选：<文件名>」
- 主按钮「开始」：蓝底白字、初始**浅灰点不动**，选到包才亮；**按 `Esc` = 取消关窗**
- **不再支持目录包** —— 目录包走命令行 `python status_gui.py --pack-import <目录>`

### 2. 导出窗（点「导出题解包…」弹它）

```
┌ 导出题解包 ─────────────────────────── ×┐
│ 场次 [牛客周赛 Round 163 ▾] 题号（空 = 整场）[  ] │   ← 第一行：场次 + 题号
│ 输出 zip [ <桌面>\牛客周赛Round163.zip ] [另存为…] │   ← 第二行：输出路径 + 另存为（同一行）
│                              [取消] [开始导出]  │   ← 弹窗底排（「开始导出」= 蓝底主按钮）
└──────────────────────────────────────────────┘
```
- 第一行：「场次」下拉（列出所有牛客周赛场次）+「题号（空 = 整场）」小输入框
- 输出行 / 另存为…：「输出 zip」长框（默认桌面）+ 它右端同一行的「另存为…」
- 弹窗底排 / 主按钮「开始导出」：右端「开始导出」蓝底白字 + 它左边「取消」

### 3. 报告窗（导入 / 导出跑完都在它里面出报告）

```
┌ 题解包 —— 导入题解包 ─────────────── ×┐   ← 窗口标题
│ 包：牛客周赛Round163.zip               │   ← 副标题（这份报告是给哪个包的，灰字）
│ ┌───────────────────────────────────┐  │
│ │（等宽字报告正文，边跑边刷）          │  │   ← 报告区
│ └───────────────────────────────────┘  │
│ 校验通过 —— 可以应用到数据根            │   ← 状态行（跑着蓝字 / 通过绿字 / 失败红字）
│                  [应用到数据根] [关闭]   │   ← 弹窗底排
└───────────────────────────────────────┘
```
- 副标题 / 报告区：「包：xxx.zip」或「导出 … → …」（灰字）；报告区是等宽字体滚动区，跑的时候实时出内容
- 状态行：一句话结论；颜色 = 跑着**蓝**、通过**绿**、失败**红**
- 主按钮「应用到数据根」/ 弹窗底排：主按钮蓝底白字，没跑完时浅灰点不动（只在导入且校验通过后可点）；底排 = 主按钮 +「关闭」

## 三、两个小浮层

- 状态浮层（表格里按 `Enter`）：六状态选项框（↑↓ 选 / `1`~`6` 直选 / `Enter` 确认 / `Esc` 取消）
- 快捷键一览（按 `?`，Shift+/）：键位表（内容 = 手册里的键位表，逐字一致）

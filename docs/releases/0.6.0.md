# TB 0.6.0

TB 成为项目的主产品：题库、题解、代码编辑、本地评测和训练记录集中在训练工作台。仓库地址保留，原流程工具移到 `legacy/`，独立的前端、后端和桌面宿主分别维护。

## 安装与升级

Windows 10/11 64 位推荐安装 `TB-Setup-0.6.0-win64.exe`，包含运行时、C++ 编译器和离线 WebView2 安装组件。便携版必须完整解压，系统需已有 WebView2。`TB-Toolchain-Sources-0.6.0.zip` 提供随包编译器对应的源码与配方。

升级前退出 TB。安装会更新程序和公共题库，保留草稿、提交代码、身份、模拟赛、经验值、加密设置和用户导入内容。旧 JSON 首次使用时迁入 SQLite，原文件保留。卸载保留运行后生成的数据。

## 修复与改进

- 内置 607 道题、607 份题解、607 份题面和 378 篇基础讲解，使用 SQLite，安装后可直接阅读题解。
- 前后端通过 API 分离；题库使用批量查询，解决打开题目时等待统计刷新的卡顿。
- 知识清单通过分组、缩进、连接线和覆盖统计展示层级。
- DeepSeek 与自定义兼容 API 支持连接测试、完整响应校验和清晰错误；公式、代码和样例保持原样。
- 默认连接已部署的排行榜，区分连接失败、正在同步和已连接但暂无通过记录。
- 按牛客、Codeforces、AtCoder、洛谷适配实际编译器控件，区分 g++ 编译器版本与 C++ 标准。
- 官方提交移到底部运行、本地提交旁边；比赛、模拟赛、排行榜与成就使用不同图标。
- 成长页面重新安排每日任务和推荐卡片，可展开更多推荐。
- 基础讲义仅关联本题讲解和明确引用，按正文去重，移除同标签扩散。当前内置题目最多关联 4 篇，Xterfusion 为 1 篇。

## 验证

165 项后端回归通过；独立 API 与前端、浏览器及原生表单适配测试通过。985 份正文中的 91,762 个公式全部通过 KaTeX 渲染。真实安装与 0.5 升级检查确认记录、身份、草稿及加密配置保留；随包 C++ 编译器通过实际本地评测。

DeepSeek 使用已保存配置的隔离副本进行了真实连接验证。日榜、周榜与总榜真实请求均返回 HTTP 200；服务当前暂无符合条件的首次通过记录。官方提交适配通过本地控件和表单验证，未进行真实账号提交。

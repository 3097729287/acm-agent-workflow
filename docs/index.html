acm-agent-workflow

给 AI agent 用的算法竞赛「题解 + 补题」流水线。把「写完题解就烂尾」变成一条 每一步都有机器闸门的流水线：抓题面 → 写代码 → 四档验证 → 生成题解 → 格式自检 → 归档对账，外加一个跟踪每道题掌握程度的状态表（带图形端）。

CI · Releases · MIT · English · 当前 v0.1.0 早期演示版（接口还会变）
GitHub 仓库 README（中文） 提意见 / 报 Bug

六步流水线

① 抓题面fetch_problem.py
② 写代码agent 写正解
③ 四档验证verify.py / md_full.py
④ 生成题解教程式写法
⑤ 格式自检check_solution.py（17 项）
⑥ 归档对账archive_check.py

「四档」= 样例 / 边界 / 对拍（与暴力随机对拍）/ 极限。每一档的数字都必须来自实跑， 没跑的档如实写「未验证」——不许编。

为什么值得用

机器闸门优先

每一步都有退出码。闸门过了就是过了，不靠自觉。

验证不是口号

对拍用暴力跑随机数据；格式闸 17 项每项带行号原句；归档按内容对账。

防 AI 编造成绩

实测记录块有格式闸卡着；写不出真实数字就交不了差。

补题不再烂尾

状态表六态流转（不会 / 待重写 / 复现AC / 独立AC / 巩固 / 未做），图形端一键改。

快速开始

git clone https://github.com/3097729287/acm-agent-workflow
cd acm-agent-workflow
python install.py --check      # 环境体检 + 示例闸门，退出码 0 = 一切就绪

然后用你的 agent 读仓库里的 AGENTS.md，照六步跑一场比赛即可。完整教程见 README。

自带的东西

  • tools/ —— 全部脚本（抓题面 / 验证 / 格式闸 / 归档 / 状态表 / 图形端…）
  • knowledge/ —— 16 篇方法文档：题解怎么写、验证怎么做、归档怎么对账
  • demo/ —— 两场示例（一场完整 + 一场跨场次迷你场），clone 下来就能跑
  • examples/ —— 故意做坏的反例，格式闸会报 8 项红（用来确认闸门真的在干活）
  • skills/check-solution/ —— 17 项格式闸的 agent skill 形态

三个入口，同一份规则

命令行

仓库里的脚本，python tools/xxx.py。

图形端

状态表 GUI，鼠标点着改状态、导入导出题解包；也能打包成单文件 exe。

GitHub Action

一行 uses: 挂到你自己仓库的 CI 上，题解不合格就变红。

题解共享

题解包是「一场题解 + 算法归档」的可搬格式：导出成一个 zip，别人一条命令导进自己的数据根， 索引、状态表、「已讲过概念」台账全都跟着走。想投稿自己的题解，把包放进 contributions/ 提 PR，CI 会先替维护者把包校验一遍。

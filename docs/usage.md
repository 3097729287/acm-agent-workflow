# 使用 TB

## 练习

在题库或知识目录选择题目，加入“训练与待办”。题面与 C++ 编辑器并排显示，支持切换布局，草稿自动保存。“运行样例”编译并对比公开样例；选择自定义输入后可运行自己的测试数据。样例通过不计入官方 AC。内存超限、启动失败等运行错误只在运行结果中显示，不弹出 Windows 错误对话框。

“提交”（Ctrl+Enter）使用你日常浏览器已登录的 Codeforces、AtCoder、牛客或洛谷账号提交，不需要在 TB 内登录。首次点击会打开连接页：在 Edge 的 `edge://extensions`（Chrome 为 `chrome://extensions`）开启开发人员模式，加载程序目录中的 `browser-extension` 文件夹，回到连接页刷新。只需启用一次扩展；请使用已登录原站的浏览器配置文件。

登录失效或需要验证码时，点击“在浏览器查看”，在原站处理后回 TB 提交。登录本身不会发送代码。界面先显示“等待原站受理”，拿到本次提交编号后显示“评测中”，确认结果后保存记录并更新进度。45 秒内没有受理编号会明确提示尚未确认，请先核对原站记录，避免重复提交。浏览器标签在收到结果后保留供核对。模拟赛期间使用受比赛规则保护的“赛内提交”。

点击题解查看内置内容，基础讲解可以按章节展开；从零讲页面可搜索概念。新抓取的公开题若尚未导入题解，会显示尚未收录。内置题解不需要配置 AI API。

模拟赛可选综合、专项或随机单题，比赛期间隐藏考点并限制题解查看；结束后在模拟赛页面复盘。提交记录保存每次提交的代码及结果。

## 翻译

设置 → 翻译 API，选择 DeepSeek 或自定义服务。官方 DeepSeek 使用 `deepseek-chat`；自定义服务填写服务商提供的 Base URL 和模型，支持根地址、`/v1` 或完整 `/chat/completions` 地址。按服务要求填写 API Key；本机无需认证的服务可留空。

保存后点击“测试连接”，成功会显示验证状态。密钥无效、余额不足、模型不存在或服务输出截断会分别给出原因。测试会使用该接口的正常用量。翻译中保留代码、公式和样例；失败时仍可直接看原文。换 Windows 用户或电脑后，原有 DPAPI 密钥需要重新配置。

## 排行榜

软件默认连接已部署的 TB 排行榜。设置 → 账号与身份可以改昵称、查看唯一 ID、修改或断开服务地址。初次连接完成后，界面自动刷新。没有首次本地审核通过的记录时，已连接的榜单可以为空；运行和仅样例通过均不计入。

日榜和周榜使用北京时间。断网时训练记录继续保存在本机，稍后同步。服务接收昵称、身份与通过摘要，不接收代码或翻译密钥。

## 外观与数据

设置可调整主题、字号、导航顺序、名称、页面组合。知识清单的分组、缩进与连接线表示层级，数字分别反映可用题目和个人覆盖。

升级前退出 TB，再运行安装程序。个人记录保存在程序目录 `state/`；不要将使用后的整个目录当作公共安装包分享。手动备份时先退出程序，再复制完整 `state/`；程序提供的数据库备份使用 SQLite 在线备份。

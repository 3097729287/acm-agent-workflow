## A. 十六进制与 2^k

### 1. 题意

给一个十六进制字符串 x（长度 ≤ 8×10^5），问它表示的整数能否被 $2^k 整除（k \le 10^5）。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string x; int k;
    cin >> x >> k          // 漏掉分号：让编译检查抓到
    cout << ((x == "0") ? "YES" : "NO") << "\n";
    return 0;
}
```

### 复杂度

设字符串长度为 n，时间复杂度是 O(\log n)。

### 正确性证明

从末位往高位数末尾零的个数即可，显然是对的。

### 手算

拿样例 x = 2A、k = 5 走一遍：十六进制每位 4 bit，末位 A = 1010，末尾一个零，
所以 v2(x) = 1，1 < 5，输出 NO。

## 实测记录

- 官方样例：3 组全过
- 随机对拍：约 500 组一致

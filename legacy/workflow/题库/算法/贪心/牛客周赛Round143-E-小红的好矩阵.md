# 牛客周赛 Round 143 E - 小红的好矩阵

- **难度**：CF 1500
- **原题链接**：https://ac.nowcoder.com/acm/contest/134529/E
- **题解位置**：`题解\牛客周赛\Round143\Round143题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\贪心\`
- **数据结构与算法**：结构刻画 + 逐段贪心
- **具体知识点**：合法矩阵只有三类（条纹链 / A-B 链 / C-D 链）、`n % 3 != 0` 直接 -1、每 3 列一段独立取更省的那种图案

## 题意（精简）

一个 01 矩阵合法 ⟺ 每个由 0 组成的四连通块大小**恰好为 3**，每个由 1 组成的四连通块大小也**恰好为 3**。
给一个 2×n 的 01 矩阵，每次可以改一个字符，求把它变成合法矩阵的最少修改次数；无解输出 -1。

**数据范围**：n ≤ 2×10^5。

## 关键点（为什么用这个算法）

1. 信号：约束是「每个连通块恰好 3 格」，强到足以把合法矩阵的结构完全定死，剩下的只是逐段比代价。
2. 朴素做法：2×n 的矩阵共 2^(2n) 种，n = 2×10^5 时无从枚举；直接 DP 又不知道该记什么状态。
3. 正解的核心是**先摸结构再算代价**：小规模全枚举 n = 3, 6, 9, 12，合法矩阵个数分别是 6、10、18、34，正好是 2^(n/3+1) + 2。由此得到结构定理 —— 合法 ⟺ 3 | n，且矩阵能按每 3 列切成 n/3 段，每段是 6 种图案之一，相邻两段接口**逐行异色**。
4. 6 种图案分成三条互不相通的链（条纹 E/F 链、C/D 链、A/B 链），链内每段都能独立二选一，所以对每段取「改成哪种最省」、代价相加即得该链最优，三条链之间再取最小。

## 复杂度

- 时间：O(n)，每段 O(1)、共 n/3 段；n = 2×10^5 时约 2×10^5 次逐格比较（实测 11 ms）
- 空间：O(n)（只存两行字符串）

## 踩过的坑

1. **忘了 `n % 3 != 0` 直接输出 -1** → 整个矩阵 2n 格要被若干个 3 格块恰好铺满，所以 3 必须整除 n；漏判 n = 1, 2 这类小情况就错。
2. **只算了一类链** → 只写条纹型或只写 C/D 链会漏掉更优解，而样例恰好落在 C/D 链上，只测样例发现不了；三类链都要算再取最小。
3. **把条纹型误写成「每列交替」** → 条纹型是「每 3 列一段」：段内 3 列颜色相同，段与段之间才互换；写成每列上下交替会算出一个偏大的答案。
4. **把接口记成「整体取反」** → 接口要求是「逐行异色」；对那两格来说结果恰好一样，但理由别记错。

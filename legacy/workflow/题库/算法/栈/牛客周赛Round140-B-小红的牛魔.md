# 牛客周赛 Round 140 B - 小红的牛魔

- **难度**：CF 900
- **原题链接**：https://ac.nowcoder.com/acm/contest/132940/B
- **题解位置**：`题解\牛客周赛\Round140\Round140题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\栈\`
- **数据结构与算法**：栈（栈消除 / 字符串重写）
- **具体知识点**：从左往右压栈，栈顶凑出 niu 弹 3 个、凑出 mo 弹 2 个；两条不变量保证「只看栈顶一次」就够——新模式必以刚压入的字符结尾、不可约串的前缀仍不可约

## 题意（精简）

给一个只含 n/i/u/m/o 的字符串。每次操作可以删掉一个**连续子串** niu 或 mo（删完两边接上），可以操作任意次。
问能不能把整个串删空：能输出 Yes，否则 No。

**数据范围**：n ≤ 2×10^5。

## 关键点（为什么用这个算法）

1. **先排除错误方向**：数字母个数是错的。官方样例 2 的 omuin 与样例 1 的 niumo 字母多重集完全一样（各一个 n,i,u,m,o），答案却一个是 No 一个是 Yes——关键在于**相邻关系**，所以需要一个能表达"相邻"的结构。
2. 栈刚好能做：压入新字符后，若出现模式，它必然覆盖最后一个字符（否则压入前就该存在），所以只检查栈顶 2~3 个字符即可，单次 O(1)。
3. 弹出后不用回头复查：弹出后的栈是"弹出前那个不可约串"的**前缀**，而不可约串的子串必然不可约。
4. 贪心安全（合流性）：两条规则的字母表不相交（n/i/u 与 m/o），且 niu、mo 都没有"真前缀 = 真后缀"的自重叠 → 无论按什么顺序删，删到不能删时剩下的串唯一，所以"见到就删"不会把能删光的串删坏。

## 复杂度

- 时间：O(n)，n = 2×10^5 时约 2×10^5 次字符操作（实测 9 ms，含进程启动）
- 空间：O(n)（用 `string` 当栈，reserve(n)）

## 踩过的坑

1. **拿字母计数当判据** → 反例 omuin（官方样例 2 就是它）：字母全对、顺序不对，答案是 No。看到"删子串 / 能不能删空"要条件反射想到栈或括号匹配。
2. **没判 m >= 3 / m >= 2** → n = 1、串是 n 时会去访问 `st[-1]`（size() 是无符号数，m-3 直接变成一个巨大的下标 → 越界崩溃）。
3. **弹出用"标记删除"** → 之后还用旧下标读栈顶，读到已删字符。用 st.resize(m - 3) 或真正 pop。
4. 别用 `stack<char>`：它不支持一次弹多个、也不能随机访问栈顶第 2/3 个字符，写起来更绕。

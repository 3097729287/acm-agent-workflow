# 牛客周赛 Round 123 E - 小红出牌（easy）

- **难度**：CF 1300
- **原题链接**：https://ac.nowcoder.com/acm/contest/125954/E
- **题解位置**：`题解\牛客周赛\Round123\Round123题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\连续段\`（本场新建）
- **数据结构与算法**：连续段（顺子 = 数轴上连续的一段）+ 在线维护
- **具体知识点**：新牌 +1、左右邻居各 −1；「最少顺子数 = 连续段数」的下界与可达性

## 题意（精简）

「顺子」= 若干张牌，排序后每相邻两张差 1（数字连续的一段）；单独一张也算顺子。
本题保证 n 张牌的数字**互不相同**。对**每个前缀** a<sub>1</sub>..a<sub>x</sub>，求把这些牌全部出成顺子所需的最少次数，
输出 n 个答案。

**数据范围**：n ≤ 10^5；a<sub>i</sub> ≤ n 且互不相同（等价于 1..n 的一个排列）

## 关键点（为什么用这个算法）

1. 数字互不相同 ⇒ 把前缀的数字画在数轴上，它就是若干**连续段**；两段之间至少空一个数字，
   永远不可能待在同一个顺子里 → 至少"段数"次；而每段内部连续，一段一次就出完 → 段数就是最小值。
2. 要对每个前缀回答，不能每个前缀重排（O(n^2)）→ **在线维护段数**：每来一张新牌 v，
   先 +1（自己算一段），若 v−1 已出现则 −1（接左边那段），若 v+1 已出现则再 −1（接右边那段）。
   互不相同保证 v 至多一个左邻一个右邻，两个都在时正好把两段焊成一段，净变化 +1−1−1 = −1。
3. 每步 O(1)，总 O(n)。

## 复杂度

- 时间：O(n)
- 空间：O(n)（一个 has 标记数组）

## 踩过的坑

1. has 数组要开到 n + 2：代码会访问 `has[v+1]`，v 最大等于 n。
2. 只判断左邻居会漏掉"接右边"的情况 → 两个邻居都要判断。
3. 输出是**读一张输出一个数**、共 n 个、空格分隔，不是一行一个。
4. 手推边界期望值时我算错过一次：3 2 1 我写成 1 2 3，实际第二张 2 就和 3 相邻并成一段，
   正确输出是 1 1 1。**跑出不一致时先重推期望值，别急着改代码**。

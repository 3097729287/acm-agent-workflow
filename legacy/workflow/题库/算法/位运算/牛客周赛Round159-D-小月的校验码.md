# 牛客周赛 Round 159 D - 小月的校验码

- **难度**：CF 1300
- **原题链接**：https://ac.nowcoder.com/acm/contest/139660/D
- **题解位置**：`题解\牛客周赛\Round159\Round159题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\位运算\`
- **数据结构与算法**：位运算 + 开桶查表
- **具体知识点**：枚举"翻哪一位"而不是枚举串对；按位分开计数

## 题意（精简）

给 n 个长度都是 b 的 01 串，保证两两不同。"单点差分码" = 恰好只有一位不同的两个串组成的**无序对**。
要输出两样：① 这样的对总数；② 对每一位（第 1 位到第 b 位，**从左往右数**），有多少对是在这一位上不同。

**数据范围**：n ≤ 2×10^5；b ≤ 20。

## 关键点（为什么用这个算法）

1. 信号：串长极小（b ≤ 20），"恰好一位不同"恰好是一次位翻转，适合把串压成整数做位运算。
2. 朴素做法枚举所有无序对：n(n-1)/2 ≈ 2×10^10 对，每对还要比 b 位，必然超时。
3. 正解：每个串看成 b 位整数 code（第 1 个字符是最高位），开桶 `has[0 .. 2^b - 1]` 记它在不在集合里，再对每个串枚举 b 个位置 j，看翻转第 j 位后的整数在不在桶里。
4. 不重不漏：任意一对差异在第 j 位，枚举到那一端时必然命中（不漏）；每一对会被它的两个端点各命中一次，所以总数与每一位的计数都要除以 2。

## 复杂度

- 时间：O(nb + 2^b)，n = 2×10^5、b = 20 时约 4×10^6 次操作（实测 0.037 s）
- 空间：O(2^b + n)，桶最多 2^20 ≈ 1.05×10^6 个状态

## 踩过的坑

1. **位置轴搞反（本题最大的坑）**：题面的"第 i 位"是字符位置、从左往右数，而二进制位是从低位数；二进制的第 j 位对应从左往右第 b - j 个字符，按 j 直接累加全错，样例 2 专抓这个。
2. 忘记除以 2：一对会被两个端点各数一遍。
3. 桶要开 2^b 那么大（b = 20 → 1048576），不是 n；b 是变化的，别把桶写死成 1024。
4. 累加量级：总对数上限 2×10^5 × 20 ÷ 2 = 2×10^6，`int` 其实装得下，但输出总和、各位计数都写成 `long long` 更省心。

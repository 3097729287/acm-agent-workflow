# 牛客周赛 Round 163 B - 小月的十六进制

- **难度**：CF 900
- **原题链接**：https://ac.nowcoder.com/acm/contest/140737/B
- **题解位置**：`题解\牛客周赛\Round163\Round163题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\位运算\`
- **数据结构与算法**：位运算（末尾零计数）+ 进制转换
- **具体知识点**：2^k 整除 x ⟺ v<sub>2</sub>(x) ≥ k；十六进制每位 4 bit，v<sub>2</sub> = 4j + ctz(v)；全零串单独判 `YES`

## 题意（精简）

给一个十六进制字符串 x（长度 1 ~ 8×10^5，可能有前导零，大小写都有）和一个整数 k（0 ~ 10^5）。
问 x 表示的整数能不能被 2^k 整除：能输出 `YES`，否则 `NO`。
说明里的第三组样例是 `x = "0"`、k = 100000 → `YES`，因为 0 = 0 × 2^100000。

**数据范围**：|x| ≤ 8×10^5；k ≤ 10^5；时限 1 秒

## 关键点（为什么用这个算法）

1. 信号：要判的是"能不能被 2^k 整除"，而 2 的幂只看二进制末尾零的个数，根本不用知道这个数具体是多少。
2. 朴素做法要把 8×10^5 位十六进制转成大整数（3.2×10^6 个二进制位）再取模，高精度笨重；`long double` 也存不下这么多位的信息。
3. 关键观察：十六进制 1 位 = 4 个二进制位。从末位往前扫，遇到 `'0'` 就累加 4；遇到第一个非 0 位 d，再累加 `ctz(d)` 后立刻停止（更高位不可能再产生末尾零）。数出的 z ≥ k 即 `YES`。

## 复杂度

- 时间：O(|x|)，最坏（全零串）要扫完整个字符串，约 8×10^5 次操作，1 秒绰绰有余
- 空间：O(|x|) 存输入串，额外变量 O(1)

## 踩过的坑

1. x = 0 不特判 → 0 能被任何 2^k 整除（它二进制末尾有无穷多个 0），但"数 0"的算法最多数到 4×|x| 个，k 一大就误判 `NO`（样例 3 正是 k = 100000）→ 用全零标记，全零直接 `YES`。
2. 只处理一种大小写 → 题面 A~F、a~f 都允许，要统一转小写再取数值。
3. 真去算这个大整数 → 3.2×10^6 位的信息 `long double` 存不下，本题考的就是"只看末尾零"。
4. `isdigit` 的入参没转 `unsigned char` → 遇到负值字符是未定义行为，比赛中很常见的隐藏 bug。

# 牛客周赛 Round 162 F - 小月的树

- **难度**：CF 1800
- **原题链接**：https://ac.nowcoder.com/acm/contest/140489/F
- **题解位置**：`题解\牛客周赛\Round162\Round162题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\DP\树形DP\`
- **数据结构与算法**：树形 DP（子树统计 + 自底向上）+ 边的点覆盖
- **具体知识点**：把"剩余块同色"转化成"盖住所有异色边"；badCnt（子树内坏边数）与 F（以该点为顶的最少点数）两个量自底向上推；再枚举最浅点 top

## 题意（精简）

一棵 n 个点的树，每点红色 R 或蓝色 B。要删掉一个**非空且连通**的点集 D（连带删边），使得剩下的每个连通块里颜色都相同（删空了也算满足）。求最少删几个点。n ≤ 2 × 10<sup>5</sup>。

**数据范围**：n ≤ 2 × 10<sup>5</sup>；树连通，颜色串只含 R / B。

## 关键点（为什么用这个算法）

1. **转化**：剩余块里若有一条两端异色的边（坏边），那两个点同属一个剩余块却颜色不同，直接违规；反过来若剩下的边两端都同色，顺着边走下去整块必然同色。所以"剩余每块同色" ⟺ "一条坏边都不剩" ⟺ "每条坏边至少有一个端点在 D 里" —— 这就是**边的点覆盖**。
2. 不能照搬一般图的最小点覆盖（NP-hard，且本题多了"D 必须连通"的限制）：一条 4 点链上 {1,3} 是点覆盖但不连通，不合法。要在树上专门设计。
3. 把根定在 1，D 是连通子树，**最浅点 top 唯一**。top 定了之后，D 的每个分支必须从某个儿子往下长（不然断开）。于是定义两个量自底向上推：
   - badCnt[u]：u 的**子树内部**的坏边数（不含 u 与父亲那条边）；
   - F[u]：以 u 为顶、盖住 u 子树内所有坏边，最少选几个点 = 1 + Σ（badCnt[v] > 0 的儿子 v）F[v]。
   u 自己在 D 里，所以边 (u, v) 无论好坏都被盖住；v 的子树里若根本没有坏边，就一个点都不用往下选。
4. 枚举 top：合法的 top 必须满足"不在它子树里的坏边最多只有 (父亲, top) 这一条"（因为 top 自己在 D 里，能盖住这一条）。用 badCnt 判断就是 total − badCnt[top] == 0，或 == 1 且 (父亲, top) 确实是坏边。答案 = 合法 top 中最小的 F[top]。
5. 递归 DFS 在 2 × 10<sup>5</sup> 的链上会爆栈（Windows 上 0xC00000FD），必须写迭代版（用 vector 当队列边遍历边长）。

## 复杂度

- 时间：O(n)（建树 + 自底向上 + 枚举 top）；实跑极限 n = 2 × 10<sup>5</sup>：颜色交替链 0.139 s、全同色链 0.144 s
- 空间：O(n)（邻接表 + 两个数组）

## 踩过的坑

1. **递归 DFS 爆栈**：n = 2 × 10<sup>5</sup> 的链递归深度就是 2 × 10<sup>5</sup>，直接栈溢出。迭代写法是硬要求，不是风格问题。
2. **badCnt 的定义不含 u 与父亲那条边**：定义错了 F 的递推会跟着错 —— 会把"父亲已经盖住的边"又当成要往下选的理由，答案偏大。
3. **D 非空**：题目明确要求非空点集，答案至少是 1；全同色的树答案就是 1（随便删一个点，剩下的还是同色一整块）。
4. **删空了也算满足**，所以最坏情况 D 可以取全部 n 个点，答案不超过 n（DP 也天然满足这点）。
5. 根节点的 parent 是 −1，判"那条唯一的例外边"时先把根排除。

# 牛客周赛 Round 143 F - 小红的网格路径 II

- **难度**：CF 1800
- **原题链接**：https://ac.nowcoder.com/acm/contest/134529/F
- **题解位置**：`题解\牛客周赛\Round143\Round143题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\DP\分布压缩DP\`
- **数据结构与算法**：路径参数化 + 分布压缩 DP
- **具体知识点**：每列走过的格子是一段连续行区间 → 只记 b<sub>j</sub>（第 j 列横移行号）；禁格等价于 b<sub>j-1</sub> 与 b<sub>j</sub> 同侧；按行号"分布"压缩状态做 DP（是分布压缩，不是位掩码状压；位掩码模板见 `DP\状压DP\`）

## 题意（精简）

在 n × m 网格里从 (1,1) 走到 (n,m)，每步只能上、下、右移动一格，不能出界、不能重复经过同一个格子。
另有 k 个禁格（两两不同、每列至多一个、起点终点不是禁格），求合法路径数对 10^9+7 取模。

**数据范围**：n, m ≤ 10^9，k ≤ 10^5。

## 关键点（为什么用这个算法）

1. 信号：坐标大到 10^9，可特殊位置只有 k ≤ 10^5 个 —— n 大不可怕，状态多才可怕。
2. 朴素做法：按 b 的取值做 DP 要 n 个状态 × m 列转移，10^9 × 10^9 量级不可行；纯 DFS 枚举路径更是指数级。
3. 关键观察一：只能向右 ⟹ 离开某一列就再也回不来；列内竖直移动又不能折返（折返必然重复经过格子）⟹ **每个被访问列走过的格子恰好是一段连续的行区间**。
4. 关键观察二：令 b<sub>j</sub> = 从第 j 列横移到第 j+1 列时的行号（b<sub>0</sub> = 1、b<sub>m</sub> = n），则路径与序列 (b<sub>1</sub>, …, b<sub>m-1</sub>) 一一对应，第 j 列的行区间就是 [min(b<sub>j-1</sub>, b<sub>j</sub>), max(b<sub>j-1</sub>, b<sub>j</sub>)]；第 j 列的禁格在第 x 行，等价于 b<sub>j-1</sub> 与 b<sub>j</sub> **同侧于 x**。
5. 关键观察三：自由列把整个分布抹成一个常数；过一趟禁格列之后分布必然只有「左侧一段常数 + 右侧一段常数 + 禁格点处为 0」这一种形态，所以状态只需一个常数 C 或三元组 (t, A, B)，逐禁格列转移、中间的自由段用闭式公式跳过（k = 0 时自然退化成 n^(m-1)）。

## 复杂度

- 时间：排序 O(k log k)，每个禁格列 O(log n)（快速幂）+ O(1)，总 O(k log k)；n = m = 10^9、k = 10^5 时实测 72 ms
- 空间：O(k)（存禁格并按列号排序）

## 踩过的坑

1. **★ 禁格列之后的 S 更新**（原文在对拍里真栽在这）→ 两段常数的总和要把**段长**乘进去：S = S_lo·(x−1) + S_hi·(n−x)；写成 S = S_lo + S_hi 就错，因为 S_lo、S_hi 看着像"和"，其实只是**每格的值**，段上分别有 x−1 格和 n−x 格。样例里 x−1 = n−x = 1 纯属巧合所以过得去，随机对拍到第 11 组才炸（n=4, m=5、禁格 (4,2)，正确答案 144 却输出 48，差了整 3 倍）。下次：写下"和"之前先问一句"这段有几格"。
2. **gap 算多了一个** → gap = j − 1 − cur 才是 b<sub>cur+1</sub> … b<sub>j-1</sub> 这 gap 个自由变量的个数，写成 j − cur 答案会偏。
3. **n = 1 没特判** → 此时 x0 = 2 > n，初值的两段表示法失效；一行网格路径唯一，中间有禁格就是 0。
4. **取模后做减法出负数** → Σ_{u>x} 用 S − Σ_{u<x} − f(x) 算更快也更稳（两段形态下 f(x) 恰好是 0），但要写成 ((S − lo − fx) % MOD + MOD) % MOD。

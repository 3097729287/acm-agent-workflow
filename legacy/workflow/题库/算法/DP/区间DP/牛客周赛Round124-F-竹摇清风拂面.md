# 牛客周赛 Round 124 F - 竹摇清风拂面

- **难度**：CF 1800
- **原题链接**：https://ac.nowcoder.com/acm/contest/126120/F
- **题解位置**：`题解\牛客周赛\Round124\Round124题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\DP\区间DP\`
- **数据结构与算法**：栈消除（判存在性）+ 圆上区间 DP（双倍串 + 枚举 n 个窗口）
- **具体知识点**：圆周不交完美匹配 ⟺ 栈消除成空串；T<sub>x</sub> 无关；dp[l][r] 的两种转移（j 在窗口内 / j 在窗口外）；圆周上两线段判交（循环序交错）

## 题意（精简）

n 个字符按顺时针放在圆周上（下标 0..n−1），第 i 个字符 s<sub>i</sub>、权值 a<sub>i</sub>。把点两两配对，只能连同字母的点，每点恰好配一次（完美匹配），配对代价 a<sub>i</sub> × a<sub>j</sub>。在所有**线段互不相交**的配对方案里求最小总代价，不存在输出 -1。多组数据。

**数据范围**：T ≤ 100；n ≤ 500，a<sub>i</sub> ≤ 10<sup>6</sup>，单文件 Σn ≤ 500；限时 1 秒。

## 关键点（为什么用这个算法）

1. 存在性：把圆周剪开摊平，一段不相交的匹配就是一对"括号"——里面自成一组能配完的点，外面同理；两端相邻时正是"删掉两个相邻相同的字符"。故**存在 ⟺ 反复删相邻相同字符能变空串**，一个栈 O(n) 判完。
2. 计数 / 求最小：圆上的最优解剪开摊平后是**直线上的不相交匹配**，于是可以把串复制成 2n、做一遍区间 DP，取 n 个长度 n 的窗口的最小值。
3. dp[l][r] = 把 l..r 配完的最小代价；l 一定和某个 j 配对：j 在窗口内 → `a[l]*a[j] + dp[l+1][j-1] + dp[j+1][r]`；j 在窗口外（跨切口）→ `a[l]*a[j] + dp[l+1][r]`（转移 ② 只需要最近的那个同字母 j）。
4. 复杂度 O(n<sup>3</sup>)；Σn ≤ 500 时实跑 0.120 s。

## 复杂度

- 时间：O(n<sup>3</sup>)，n = 500 实跑 0.120 s
- 空间：O(n<sup>2</sup>)（dp 表 (2n+2)<sup>2</sup> 个 `__int128`，n = 500 约 16 MB）

## 踩过的坑

1. **空区间的下标是 −1，绝不能写进数组**。递推里"长度 0"的区间是 r = l − 1；我第一版写了 `dp[l][l-1] = 0`，-1 被转成 unsigned 变成天文数字，**越界写把堆写坏**（退出码 0xC0000374 STATUS_HEAP_CORRUPTION，连官方样例都跑不出来）。做法：空区间只在用到的地方用 0 顶上，不写数组。
2. **dp 尺寸按双倍串开够**：窗口起点 k 最大 n − 1 ⟹ r 最大 2n − 1、l + 1 最大 2n，所以要开 (2n + 2) × (2n + 2)。
3. **性能坑**：最初写成"对 n 个切口各做一遍完整 DP"，n = 500 全同字母时 **33.9 秒**（限时 1 秒）→ 改成"一次双倍串 DP + 取 n 个窗口"后 **0.115 秒**。同样的算法骨架，写法差 300 倍。
4. **圆周判交别用数轴开区间**：正确判据是四端点按 i k j l 或 i l j k 交错（两个方向都交错）。暴力的第一版用数轴开区间判交，把"共享端点 / 相邻"误判成交叉，对拍时才开始不一致。
5. **代价要 64 位以上**：单对可达 10<sup>12</sup>、250 对可达 2.5 × 10<sup>14</sup>，`int` 必爆；中间值用 `__int128`，输出再转 `long long`。

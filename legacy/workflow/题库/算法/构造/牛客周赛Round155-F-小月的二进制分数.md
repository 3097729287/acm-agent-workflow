# 牛客周赛 Round 155 F - 小月的二进制分数

- **难度**：CF 1600
- **原题链接**：https://ac.nowcoder.com/acm/contest/138240/F
- **题解位置**：`题解\牛客周赛\Round155\Round155题解.md`（F 题「从零讲：二进制小数展开是"长除法"，以及怎么反着构造」节，含完整推导）
- **归档文件夹**：`算法\构造\`
- **数据结构与算法**：构造（二进制小数长除法展开 + 反着构造）、字符串
- **具体知识点**：把 $n$ 个 01 串串接成 $S$，再让展开是 0.(L 个 0)(S)(S)…，其值正好 $\frac{S}{2^L(2^{|S|}-1)}$；取 $p=S$ 去前导 0、$q=C$ 个 1 后接 $L$ 个 0，即满足 $0<p<q$ 且展开必含每个 $s_i$

## 题意（精简）

给定 $n$ 个非空 01 串，构造二进制正整数 $p,q$（$0<p<q$，$1\le|p|<|q|\le1000$，$|x|$ 为二进制位数），使每个 $s_i$ 都是分数 $p/q$ 的标准二进制小数展开 $d_1d_2\ldots$ 的连续子串。输出 $p,q$ 的二进制串及每个 $s_i$ 的起始位置 $a_i$（从 1 计）。本题所有合法输入都有解。

**数据范围**：$1\le n\le 10^3$；$1\le|s_i|\le 10^3$ 且 $\sum|s_i|\le 10^3$；输出要满足 $1\le|p|<|q|\le 1000$、$1\le a_i+|s_i|-1\le 2\times10^3$。

## 关键点（为什么用这个算法）

1. 信号：标准二进制展开就是长除法 $r_0=p,\ d_j=\lfloor 2r_{j-1}/q\rfloor,\ r_j=(2r_{j-1})\bmod q$；余数只有 $q$ 种，序列终归周期。
2. 反着想：先串接所有 $s_i$ 得 $S$（每个 $s_i$ 自然连续出现），再让展开是 0.(L 个 0)(S)(S)…。这个循环串的值正是 $\frac{S}{2^L(2^{|S|}-1)}$，其标准展开就是 0.(L 个 0) 后 S 一直循环，必然含每个 $s_i$。
3. 于是 $p$ 取 $S$（去前导 0）作为 $C=|S|$ 位值，$q$ 取 $C$ 个 1 后接 $L$ 个 0 的二进制；$L=0$（$S$ 以 0 开头）或 $L=1$（$S$ 以 1 开头）保证 $|p|<|q|$。位置 $a_i=L+(\text{1-based 在 }S\text{ 中的位置})$。

## 复杂度

- 时间：$O(\sum|s_i|)$，只做串接与拼接
- 空间：$O(\sum|s_i|)$ 存 $S$ 与各串

## 踩过的坑

1. 全 0 串 $S$ 要特判：输出 $p=1,q=10$（展开 0.1000… 含任意长 0 串），$a_i=2$；直接套公式会出 $p=0$ 非法。
2. 全 1 串 $S$ 不特判会让 $p$ 与 $q$ 等长甚至相等（不满足 $p<q$）：前缀补一个 0 得 0S，既仍含原串又拉开 $|p|<|q|$。
3. $p$ 去前导 0 时若全 0 要兜底成 `"0"`，但全 0 已走特判；二进制串禁止前导 0，`q` 的 $C$ 个 1 后接 $L$ 个 0 自然无前导 0。

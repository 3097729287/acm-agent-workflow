# 牛客周赛 Round 123 C - 小红出对

- **难度**：CF 1300
- **原题链接**：https://ac.nowcoder.com/acm/contest/125954/C
- **题解位置**：`题解\牛客周赛\Round123\Round123题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\构造\`
- **数据结构与算法**：构造（上界 + 达到上界）
- **具体知识点**：按「牌面数字」分组，组内按花色去重 → 上界 2×⌊d/2⌋；按花色首次出现顺序取牌再顺次配对即可达到上界

## 题意（精简）

n 张牌，每张有牌面数字 a<sub>i</sub> 和花色 c<sub>i</sub>（A/B/C/D）。每次打出一个「对」＝两张数字相同的牌；
限制是**所有打出的牌里不能有两张「花色 + 数字」都相同的牌**。求最多能打出多少张，并输出一种方案
（每行两个下标，表示这一对打的是第几张牌）。Special Judge，方案任意。

**数据范围**：n ≤ 2×10^5；a<sub>i</sub> ≤ 2×10^5；花色只有 4 种

## 关键点（为什么用这个算法）

1. 限制的真正含义：**对同一个数字，打出的牌花色必须两两不同**（否则就撞出两张"花色 + 数字"相同的牌）。
2. 于是每个数字 v 的上界只取决于它有多少**种**花色：设 d<sub>v</sub> 为不同花色的种类数，
   打出的张数必须成双（两张一对）且花色不重复 → 最多 2×⌊d<sub>v</sub>/2⌋ 张。
   各数字之间互不影响（限制卡的是"花色 + 数字"这个组合），所以总上界就是各数字上界之和。
3. 达到上界的构造：每个数字内部按**输入顺序**扫一遍，每种花色只取第一次出现的那张（花色必然两两不同），
   丢掉多余的一张凑成偶数，再顺次两两配对——每对数字相同、花色不同，合法。
   上界可达 ⇒ 就是最大值。复杂度 O(n + 值域)。

## 复杂度

- 时间：O(n + 值域)（按数字分组 O(n)，每组最多看 4 种花色，输出 O(n)）
- 空间：O(n + 值域)（`vector<int> ids[值域]` 存每个数字的牌下标）

## 踩过的坑

1. 输出的下标是**输入顺序**（第几张牌，从 1 开始），不是牌面数字 → 样例 1 输出 3 5 指的是第 3、5 张牌。
2. 第一行输出的是**张数**不是对数，且必须是偶数（后面跟 k/2 行）。
3. 每换一个数字要**重新清空**花色标记数组，否则会把上一个数字的花色带过来，多算张数。
4. 本题是 Special Judge，牛客"自测运行"可能报错 → 要自己按"数字相同 + 花色不重复 + 下标不重复"三条核对。

# 牛客周赛 Round 140 F - 小红的三角形构造

- **难度**：CF 1500
- **原题链接**：https://ac.nowcoder.com/acm/contest/132940/F
- **题解位置**：`题解\牛客周赛\Round140\Round140题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\构造\`
- **数据结构与算法**：构造（勾股数参数化 / 不定方程 c² - b² = x²）
- **具体知识点**：(c-b)(c+b) = x² 拆因子；x 奇取 d=1，x 偶取 d=2；x = 1, 2 无解

## 题意（精简）

每组给一个正整数 x，要构造一个**非退化**直角三角形（三边正整数、任意两边之和大于第三边），要求**至少有一条边恰好等于 x**。
不存在输出 No；存在输出 Yes 再输出三个整数 a, b, c（每组一行 x，多组数据，多解任意，Special Judge）。

**数据范围**：T ≤ 10^5，1 ≤ x ≤ 10^9，输出三边 1 ≤ a, b, c ≤ 9×10^18。

## 关键点（为什么用这个算法）

1. 让 x 当**直角边**，设另一直角边 b、斜边 c：c² - b² = x²，即 **(c - b)(c + b) = x²**——把"找两条边"变成"把 x² 拆成同奇偶的两个因子"。
2. 由 d = c - b、x²/d = c + b 得 b = (x²/d - d)/2、c = (x²/d + d)/2。
3. x 为**奇数**：x² 是奇数，取 d = 1（同奇偶）→ (x, (x²-1)/2, (x²+1)/2)（两条边是相邻整数）。
4. x 为**偶数**：d = 1 会算出半整数，取最小的同奇偶因子对 d = 2 → (x, (x/2)² - 1, (x/2)² + 1)。
5. x = 1：(c-b)(c+b) = 1 只能是 c-b = c+b = 1 → b = 0；x = 2：因子对只有 (1,4)（奇偶不同）与 (2,2)（b = 0）→ 两者都无解。x ≥ 3 恒有解。

## 复杂度

- 时间：每组 O(1)（只看 x 的奇偶），T = 10^5 实测 49 ms
- 空间：O(1)

## 踩过的坑

1. **x = 1、2 没特判**：x=1 会输出 b = 0（非法边长），x=2 会算出 (x²-1)/2 这种半整数（整数除法悄悄截断，输出错答案但没报错）。
2. **x * x 用 `int`**：x ≤ 10^9 → x² ≤ 10^18，`int` 溢出成垃圾数（官方样例 x 很小，抓不到）。中间量一律 `long long`（上限 9.22×10^18，够）。
3. **奇偶分支写混**：偶数分支是 (x/2)²，不是 x²/2；奇数分支直接用 c = b + 1 最省事。
4. **Special Judge 的自测陷阱**：本题多解，牛客"自测运行"可能对着固定答案比、把你的正确答案判错。本地自检三件事：min(a,b,c) ≥ 1、排序后 p² + q² = r²、x 在其中（大数用 Python 校验，`C++` 的 a*a 也能装下，但 Python 更省心）。

# 牛客周赛 Round 124 E - 云卷疏帘观月

- **难度**：CF 1800
- **原题链接**：https://ac.nowcoder.com/acm/contest/126120/E
- **题解位置**：`题解\牛客周赛\Round124\Round124题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\结论与计数\`
- **数据结构与算法**：阈值分解（mex 之和 → 按阈值数区间）+ 最优结构的刻画与计数 + 快速幂
- **具体知识点**：mex(S) = #{x ≥ 1 : mex(S) ≥ x}；T<sub>x</sub> = (lo+1)(n−hi)；"挤到极限"的最优排列；最优个数 = 2<sup>⌊n/2⌋</sup>

## 题意（精简）

长度为 n 的**优美序列** = 0..n−1 的一个排列。权值 W = 所有子段（含单点段）mex 之和。问权值达到最大的排列有多少个，对 10<sup>9</sup>+7 取模。

**数据范围**：n ≤ 10<sup>9</sup>；限时 1 秒。样例：n = 2 → 2；n = 5 → 4。

## 关键点（为什么用这个算法）

1. n 到 10<sup>9</sup>，排列数不可枚举，只能找**结论**；而问的是"个数"，答案必然是某个可快速幂的量的组合。
2. 第一个关键（把整体量拆开）：mex(S) = #{x ≥ 1 : mex(S) ≥ x}，于是 W = Σ<sub>x≥1</sub> T<sub>x</sub>，其中 T<sub>x</sub> = 含全部 0..x−1 的段数。mex 是整体量、无法乘；T<sub>x</sub> 只跟这 x 个值的位置有关，可以乘。
3. 第二个关键（T<sub>x</sub> 的乘法形式）：记 lo/hi 为 0..x−1 这些值下标的最小 / 最大值，则 **T<sub>x</sub> = (lo + 1)(n − hi)** —— 左端点要 ≤ lo、右端点要 ≥ hi。
4. 第三个关键（最优结构）：想让每个 T<sub>x</sub> 都大，就要让 0..x−1 挤在一起；把 0 放正中间、1/2/3… 交替往两边贴（奇数在左降序、偶数在右升序）就能"挤到极限"。n = 9 的最优排列 7 5 3 1 0 2 4 6 8，T 向量是 25 20 16 12 9 6 4 2 1（和 = 95 = 直接算 mex 的结果）。
5. 计数：贴中点的那一对（1 和 2）可以左右互换，往外每加一层多一次独立的"贴左还是贴右"，共 ⌊n/2⌋ 次，故最优个数 = **2<sup>⌊n/2⌋</sup>**（n = 1 时指数 0，2<sup>0</sup> = 1，也对）。

## 复杂度

- 时间：O(log n)（快速幂），实跑极限 n = 10<sup>9</sup> 时 0.008 s
- 空间：O(1)

## 踩过的坑

1. **"最大权值"的闭式我手推错了四次**。权值本身实测是（n = 1..11）1, 3, 7, 13, 22, 34, 50, 70, 95, 125, 161，它的增量规律是 d(2m) = m<sup>2</sup> + m、d(2m+1) = (m+1)<sup>2</sup>（从 M(1)=1、M(2)=3、M(3)=7 起累加）。教训：**看起来像的闭式一定要让脚本跑一遍再写进题解**；而且"个数对了"不等于"权值公式对了"，所以暴力里同时打了权值和公式两个值对比。
2. **别把"最大权值"和"最优个数"搞混**：题面问的是个数（2 的幂），权值是三次级别的量，程序里根本不出现。
3. **快速幂的指数是 n / 2（整除）**：n = 1 时指数为 0，不必特判。

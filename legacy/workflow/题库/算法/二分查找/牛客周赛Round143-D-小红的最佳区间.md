# 牛客周赛 Round 143 D - 小红的最佳区间

- **难度**：CF 1300
- **原题链接**：https://ac.nowcoder.com/acm/contest/134529/D
- **题解位置**：`题解\牛客周赛\Round143\Round143题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\二分查找\`
- **数据结构与算法**：排序 + 二分查找（Bound）
- **具体知识点**：相交数化成 #{l<sub>i</sub> ≤ L+k} − #{r<sub>i</sub> &lt; L}、排序后两次 bound、候选 L 缩到 {l<sub>i</sub> − k}

## 题意（精简）

给 n 个闭区间 [l<sub>i</sub>, r<sub>i</sub>]，自己另选一个**长度恰好为 k** 的闭区间 [L, L+k]（L 是任意整数，可以为负），问最多有多少个给定区间与它相交，端点重合也算相交。
只要输出这个最大个数。

**数据范围**：n ≤ 2×10^5，0 ≤ k ≤ 10^9，0 ≤ l<sub>i</sub> ≤ r<sub>i</sub> ≤ 10^9。

## 关键点（为什么用这个算法）

1. 信号：L 的取值是 −10^9 ~ 10^9 量级的连续整数域，但「相交」这件事能拆成两个只跟单端点有关的计数。
2. 朴素做法枚举所有 L 再逐个区间判相交是 O(值域 × n)，10^9 × 2×10^5 量级不可行。
3. 关键观察一：[l<sub>i</sub>, r<sub>i</sub>] 与 [L, L+k] 相交 ⟺ l<sub>i</sub> ≤ L+k 且 r<sub>i</sub> ≥ L，于是相交数 = A(L+k) − B(L)，其中 A(t) = #{l<sub>i</sub> ≤ t}、B(t) = #{r<sub>i</sub> &lt; L}；减掉的正是「完全落在窗口左边」的那批区间。A 只依赖 L+k、B 只依赖 L，都能排序 + 二分 O(log n) 求出。
4. 关键观察二：A(L+k) 与 B(L) 都只升不降，f(L) = A − B 是阶梯函数，台阶只出现在 L = l<sub>i</sub> − k（升）和 L = r<sub>i</sub> + 1（降）；最大值必能在某个上升点取到 ⟹ 只需枚举 L ∈ {l<sub>i</sub> − k}（代码里再加 {r<sub>i</sub>}、{r<sub>i</sub>+1} 兜底，只多花常数时间）。

## 复杂度

- 时间：排序 O(nlog n)；3n 个候选 × 两次二分 O(log n)，总 O(nlog n)，n = 2×10^5 时实测 185 ms
- 空间：O(n)（两个排序数组 + 候选集）

## 踩过的坑

1. **把端点重合的区间误判成不相交** → 端点重合算相交，所以 B 必须**严格小于**：#{r<sub>i</sub> &lt; L} 要用 `lower_bound`（找第一个 ≥ L），写成 `upper_bound` 就错。下次：闭区间相交的两个条件一松一紧，动手前先把等号归谁念一遍。
2. **两个二分抄混** → A 是 l<sub>i</sub> ≤ L+k，用 `upper_bound`；B 用 `lower_bound`，松紧方向正好相反。
3. **中间量溢出** → L = l<sub>i</sub> − k 能到 −10^9、L + k 能到 2×10^9，要全程 `long long`。
4. **以为 k = 0 要特判** → 窗口退化成单点 [L, L]，公式照样成立。

### 附：`lower_bound` / `upper_bound` 语义速记

> 原是本文件夹里的一份散 txt（`demo.txt`），2026-09-30 清理时并进本文，内容未改。

- `lower_bound(首迭代器, 尾迭代器, 值);` —— 返回**第一个 ≥ 值**的元素位置。如果所有元素都 < 值，返回尾迭代器。
- `upper_bound(首迭代器, 尾迭代器, 值);` —— 返回**第一个 > 值**的元素位置。如果所有元素都 ≤ 值，返回尾迭代器。

对照上面「踩过的坑」第 1、2 条：要数 #{r<sub>i</sub> < L} 就用 `lower_bound`（返回第一个 ≥ L 的，它的下标正好等于 < L 的个数）；要数 #{l<sub>i</sub> ≤ L+k} 就用 `upper_bound`。

## 题意（精简）

有 n 种互不相同的非空小写字符串 s<sub>i</sub>，第 i 种有 c<sub>i</sub> 个（0 ≤ c<sub>i</sub> ≤ 10^9）。
q 次询问，每次给一个串 t：在所有"是 t 的前缀且剩余数量 c<sub>i</sub> &gt; 0"的 s<sub>i</sub> 中挑最长的，输出它的编号并让 c<sub>i</sub> 减 1；不存在就输出 0 且数量不减。

**数据范围**：所有 s<sub>i</sub> 与所有 t<sub>i</sub> 的长度之和 ≤ 5×10^5；内存限制 256 MB

## 关键点（为什么用这个算法）

1. 信号：每次询问要找的是"一堆串里，是 t 的前缀的那几个"中最长的——前缀关系天然就是 Trie 的形状。
2. 朴素做法每次把 n 个 s<sub>i</sub> 都拿出来，用 t 的前 |s<sub>i</sub>| 个字符和 s<sub>i</sub> 逐个比较，单次 O(n · |t|)；n 和 q 都到 2×10^5 级别，稳稳超时。
3. 正解：t 的所有前缀恰好是 Trie 上从根出发、沿 t 的字符一个一个往下走所经过的那条路径上的结点。把所有 s<sub>i</sub> 插进 Trie 并在结束结点记下编号；查询时边走边看"这里有没有结束的串、它的余量是否大于 0"，越走越深，最后一次更新就是最长合法前缀；某个字符没有儿子就直接跳出。
4. 不用"哈希 + 枚举所有前缀"：对每个前缀算哈希或比较都要额外花时间，容易退化；Trie 直接把前缀集合组织成一条路径，最贴合本题。

## 复杂度

- 时间：O(Σ|s<sub>i</sub>| + Σ|t<sub>i</sub>|)，插入与查询都是每个字符 O(1)（字母表固定 26），总量 ≤ 5×10^5
- 空间：O(26 · Σ|s<sub>i</sub>|)，按原文实现（结点数上界取 5×10^5 的 `int` 儿子数组）约 50 MB，限 256 MB（想更省可改成每个结点用 map/链表存儿子）

## 踩过的坑

1. 结点编号从 0 开始新建 → 0 既当根、又当"没有这个儿子"的哨兵，新结点必须从 1 开始编号，否则子结点会和根/空指针混淆。
2. 找到第一个合法前缀就 `break` → 题目要的是最长而不是最先找到；路径是从浅到深，直接用新发现的覆盖旧答案即可。
3. 数组按 n 开小 → 结点数上界是"所有字符串长度之和 + 1"，要按 5×10^5 开。
4. `cnt` 和 `id` 两个数组混用 → `cnt[i]` 按字符串编号索引，`id[v]` 才是结点到编号的映射，别按结点去查 `cnt`。

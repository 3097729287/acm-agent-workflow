## 题意（精简）

有一条有向闸门线段 P1(u1,v1) → P2(u2,v2)，以该方向为准左侧是库内、右侧是库外。
有 n 条物品移动线段，第 i 个物品从 (a<sub>i</sub>,b<sub>i</sub>) 直线走到 (c<sub>i</sub>,d<sub>i</sub>)（允许是同一个点）。
只有交点严格落在两条线段内部才算"穿过"：交点是任一条线段的端点不算，两线段有重合部分（含完全重合）也不算。
物品从库外穿到库内则库内 +1，从库内穿到库外则 −1，求全部移动结束后库内的变化量。

**数据范围**：坐标到 10^6（叉积可达约 8×10^12，必须 `long long`）；原文未标注 n 的上限

## 关键点（为什么用这个算法）

1. 分两步：先判"有没有真正穿过"，再判"穿的方向"。
2. 硬解交点要处理除法与浮点误差，还要单独应付端点、共线、重合一堆退化情形。
3. 正解用叉积符号：`d1 = cross(P1,P2,起点)` 与 `d2 = cross(P1,P2,终点)` 严格异号，同时 `d3 = cross(起点,终点,P1)` 与 `d4 = cross(起点,终点,P2)` 也严格异号 → 真穿过。任一为 0（端点落在对方直线上）或同号都不算，正好对上题面的退化约定。
4. 方向：真穿过时起点必不在闸门直线上（否则 `d1 = 0` 已被排除），`d1 > 0` 表示起点在 P1 → P2 的左侧即库内 → 出库 −1；`d1 < 0` → 入库 +1。

## 复杂度

- 时间：O(n)（每条记录 4 次叉积）
- 空间：O(1)（不存数据，边读边算）

## 踩过的坑

1. 写成 `d1 * d2 < 0` 判异号 → 坐标到 10^6 时叉积约 8×10^12，两个相乘约 6.4×10^25，`long long` 直接溢出 → 改成 `(d1 > 0 且 d2 < 0) 或 (d1 < 0 且 d2 > 0)` 这种符号比较。
2. 比较写成 ≤ / ≥ → 端点相交按题意不算穿过，所有判断必须严格 < 0 / > 0。
3. 左右写反 → 本题是常规数学系（y 轴向上），`cross(P1,P2,X) > 0` 才是左侧（库内）；写反了样例 1 会输出 −1 而不是 1。
4. 想给共线重合、起点等于终点的退化线段写特判 → 不用：共线时 `d1 = d2 = 0`，退化线段 `d1 == d2`，都会被"严格异侧"自动排除。

# 牛客周赛 Round 140 E - 小红的排序（hard）

- **难度**：CF 1500
- **原题链接**：https://ac.nowcoder.com/acm/contest/132940/E
- **题解位置**：`题解\牛客周赛\Round140\Round140题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\并查集\`
- **数据结构与算法**：并查集（位置图连通性）
- **具体知识点**：约束放宽只让边变少；建边条件 i + x ≤ n 本来就在代码里，x, y < n 无需任何改动

## 题意（精简）

与 D 题（小红的排序 easy）唯一区别在约束：D 保证 x, y ≤ ⌊n/2⌋，本题只保证 x, y < n。
其余完全相同：每次交换 p<sub>i</sub> ↔ p<sub>i+x</sub> 或 p<sub>i</sub> ↔ p<sub>i+y</sub>（下标越界不允许），问能否排成升序。

**数据范围**：T ≤ 2×10^4，4 ≤ n ≤ 2×10^5，1 ≤ x < y < n，单个测试文件 Σn ≤ 2×10^5。

## 关键点（为什么用这个算法）

1. **hard 版不比 easy 版多任何算法**：交换规则一字不改，x、y 变大只是让合法的交换对**变少**，而 i + x ≤ n 这个条件本来就写在 D 的代码里 → **D 的代码直接提交 E 即可通过**（两题代码去掉注释与空行后 44 行逐字一致，只有注释措辞不同）。
2. 真正会挂的是"被 easy 的额外保证误导"：看到 x, y ≤ ⌊n/2⌋ 就想找规律（"图一定连通"、"按 `gcd(x, y)` 分类"），这类判据在 E 里不成立（会挂）。
3. 正确姿势始终是：老实建位置图 + 并查集，判"值 v 与它当前所在位置同块"。建边 O(n)，Σn ≤ 2×10^5 完全跑得动。
4. 官方样例 1 第二组 n=5, x=2, y=4：x=2 连 1-3, 2-4, 3-5，y=4 连 1-5，得到 {1,3,5} 与 {2,4} 两块；值 2 停在位置 3 → No。

## 复杂度

- 时间：O(Σn · α(n))（实测 22 ms）
- 空间：O(n)

## 踩过的坑

1. **在 easy 上"总结"出一个只在 easy 成立的判据**（整除 / 连通 / 块数等于 `gcd` 之类）→ E 直接挂。**只信建图 + 并查集，不信规律**（实测随机对拍里既有"两块"的 n=8, x=2, y=4，也有块数还受 i+x ≤ n 影响的例子）。
2. 其余坑与 D 题相同（判断方向、递归 `find`、多组数据清空、每组重开大数组），详见 `牛客周赛Round140-D-小红的排序（easy）.md`。
3. 别把交换对象当成"值相差 x"：换的是**下标**相差 x。

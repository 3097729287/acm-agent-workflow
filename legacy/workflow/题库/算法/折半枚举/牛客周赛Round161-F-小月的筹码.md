# 牛客周赛 Round 161 F - 小月的筹码

- **难度**：CF 1500
- **原题链接**：https://ac.nowcoder.com/acm/contest/140235/F
- **题解位置**：`题解\牛客周赛\Round161\Round161题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\折半枚举\`（2026-10-01 新建，本场第一份记录）
- **数据结构与算法**：折半枚举（meet-in-the-middle）+ 异或消去律 + 二分查找
- **具体知识点**：枚半边 2^(n/2) 个子集、按 (个数, 异或值) 压表、用 `v1 xor v2 = x ⟺ v2 = v1 xor x` 反查右半、同键合并后配对是乘法

## 题意（精简）

n 个带编号的筹码，选恰好 k 个，使所选数字的异或和等于 x。问方案数（对 10⁹+7 取模）。两个方案不同 ⟺ 存在某个筹码一个选了另一个没选（数值相同的筹码按不同下标算）。

**数据范围**：1 ≤ n ≤ 40；0 ≤ k ≤ n；0 ≤ x < 2³⁰；0 ≤ a<sub>i</sub> < 2³⁰。

## 关键点（为什么用这个算法）

1. n = 40 是个信号：2⁴⁰ ≈ 1.1 × 10¹² 枚举不完，2²⁰ ≈ 105 万可以 —— 典型的折半规模。
2. 拆成左右各 20 个，各枚举一遍子集，记录 (选了几个, 异或值)。左半选法是 (c<sub>1</sub>, v<sub>1</sub>) 时，右半必须满足 c<sub>2</sub> = k − c<sub>1</sub> 且 v<sub>2</sub> = v<sub>1</sub> xor x —— 由异或消去律反推出来，一个查表就完事。
3. 左右各自把相同 (个数, 异或值) 的方案数合并，配对时是**乘法**（左 p 种 × 右 q 种）。
4. 线性基不行：它能回答「能不能凑出 x」和「不限个数的方案总数」，但本题**卡死必须选 k 个**，线性基的 2^(n−r) 个解按个数不均匀分布，数不出来。

## 复杂度

- 时间：O(2^(n/2) × log 2^(n/2))，n = 40 时两侧各 105 万项，排序 + 每项一次二分 ≈ 2 × 10⁷ 次基本操作。
- 空间：两侧各约 105 万个 (key, 计数) 对，约 32 MB。

## 踩过的坑

1. k = 0 时答案是 1（x = 0，空集异或和是 0）还是 0（x ≠ 0）—— 别漏了空集这一项。
2. 数值相同的筹码算不同方案（枚举的是下标集合），不要去重。
3. 乘法那一步 `p × q` 能到 10¹⁸ 量级，每步都要取模，攒着最后取会爆 `long long`。
4. 关键字编码：异或值 < 2³⁰、个数 ≤ 40，用 `(个数 << 32) | 异或值` 塞进一个 `unsigned long long`，两者不会串位。
5. `c2 = k − c1` 可能越界（负或 > R），要先判再查，别拿越界的 key 去二分。

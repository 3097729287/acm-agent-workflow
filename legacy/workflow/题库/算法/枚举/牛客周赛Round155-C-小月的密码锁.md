# 牛客周赛 Round 155 C - 小月的密码锁

- **难度**：CF 1200
- **原题链接**：https://ac.nowcoder.com/acm/contest/138240/C
- **题解位置**：`题解\牛客周赛\Round155\Round155题解.md`（C 题「思路」节：枚举三种量）
- **归档文件夹**：`算法\枚举\`
- **数据结构与算法**：暴力枚举（分界点 + 两段偏移）+ 逐位比较
- **具体知识点**：方案空间 = 分界 $c\in[0,n]$ × 前段偏移 $p\in[0,4]$ × 后段偏移 $q\in[0,4]$，共 $(n+1)\times 25$ 种；循环移动写成 `(ch - 'A' + p) % 5`；每位按 $i<c$ 决定用 $p$ 还是 $q$

## 题意（精简）

长度 $n$ 的密码，每位是 A~E 且按 A→B→C→D→E→A 循环。选分界 $c$：前 $c$ 位整体循环移动 $p$ 次、后 $n-c$ 位移动 $q$ 次（$p,q\in[0,4]$）。求移动后的串与目标串 $t$ 最少有几位不同。

**数据范围**：$1\le n\le 10^3$；$s,t$ 只含 A~E（$p,q$ 各只有 5 种取值）。

## 关键点（为什么用这个算法）

1. 信号：题面把可选的量直接点名了——$c,p,q$ 三个量，$c$ 有 $n+1$ 种、$p,q$ 各 5 种，方案空间 $(n+1)\times 25\le 2.5\times 10^4$；每种方案 $O(n)$ 逐位判定，总 $O(n^2\cdot 25)\le 2.5\times 10^7$，刚好落在暴力能过的范围。
2. 不需要更巧的做法：偏移是整段统一作用、与位置无关，逐位套同一个模 5 加法即可，不必为每段单独建表。
3. 循环移动 = 模 5 加法：`(ch - 'A' + p) % 5`；$p=0$ 表示不动，枚举时不能漏。

## 复杂度

- 时间：$O(n^2\cdot 25)$，$n=1000$ 时约 $2.5\times 10^7$ 次比较（实测 0.022 s）
- 空间：$O(n)$ 存两个串

## 踩过的坑

1. **边界分界**：循环要写成 $c\in[0,n]$ 且能取到两端——$c=0$（整串用 $q$）与 $c=n$（整串用 $p$）都是合法方案，漏一种就可能过不了样例。
2. **偏移方向**：A→B→C…是「加」，把偏移当减法用（或 `%5` 前没先把字符转成 0..4 的相对量）会整体错位。
3. **只枚举 $p$ 忘了 $q$**：前后两段偏移相互独立，$5\times 5$ 种组合要全枚举，只试 $p=q$ 会漏解。

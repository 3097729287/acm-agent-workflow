# 牛客周赛 Round 162 D - 小月的字带

- **难度**：CF 1500
- **原题链接**：https://ac.nowcoder.com/acm/contest/140489/D
- **题解位置**：`题解\牛客周赛\Round162\Round162题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\递推\`
- **数据结构与算法**：字符串长度的翻倍递推 + 结构观察（首尾不变）
- **具体知识点**：不能构造字符串时，只对"要统计的量"写递推；两处接缝各贡献一次

## 题意（精简）

字带初始只有一个字符 c<sub>0</sub>。做 n 次复制，第 i 次用的字符是 c<sub>i</sub>：把当前串 s 翻转得 s′，字带变成 s + c<sub>i</sub> + s′。问最终串里有多少对相邻的相同字符。n ≤ 60（最终长度 2<sup>n+1</sup> − 1，绝不能构造）。

**数据范围**：n ≤ 60；字符是小写字母；n = 0 时第二行输入不存在。

## 关键点（为什么用这个算法）

1. 直接构造是 2<sup>61</sup> 个字符，想都别想，只能对"相邻相同对数" f 写递推。
2. 关键观察：一次复制后，**新串的首字符 = s 的首字符，尾字符 = s′ 的尾 = s 的首字符**。初始首尾都是 c<sub>0</sub>，归纳下去：不管复制多少轮，首尾永远都是 c<sub>0</sub>。这一步把"接缝处是什么字符"这个依赖于整串的问题，变成了跟 c<sub>0</sub> 比一次。
3. 新串的相邻相同对来自四处：s 内部 f(s)、s′ 内部 f(s)（翻转不改变相邻相同）、左接缝 [last(s) == c<sub>i</sub>]、右接缝 [c<sub>i</sub> == s′ 的首字符]。后两者其实是同一个条件，于是

   f(新) = 2 × f(s) + 2 × [c<sub>i</sub> == c<sub>0</sub>]

4. 第 i 轮的贡献会被后面 n − i 轮各翻倍一次，系数是 2<sup>n−i+1</sup>（**不是** 2<sup>n−i</sup>），直接累加即可，O(n)。

## 复杂度

- 时间：O(n)（只读 n 个字符）；实跑极限 n = 60 用时 0.116 s
- 空间：O(1)

## 踩过的坑

1. **系数是 2<sup>n−i+1</sup> 不是 2<sup>n−i</sup>**：第 i 轮产生的那 2 点贡献自己也要参与后面每一轮的翻倍，样例里第一轮贡献 8 不是 4。
2. `1LL << 61` 里的 1 必须是 long long 的 1（写作 1LL），写成 `1 << 61` 是 int 移位，溢出且未定义。答案上界 2<sup>61</sup> − 2 = 2305843009213693950，`long long` 刚好装得下。
3. n = 0 时**没有第二行输入**，在循环里读字符天然安全；写成"先读一行再判 n"会读进垃圾。
4. 别被 reverse 吓到：翻转串的相邻相同对数与原串完全相同，不需要真的翻转。

# 牛客周赛 Round 123 D - 小红打牌

- **难度**：CF 1500
- **原题链接**：https://ac.nowcoder.com/acm/contest/125954/D
- **题解位置**：`题解\牛客周赛\Round123\Round123题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\组合计数\`（本场新建）
- **数据结构与算法**：组合计数（可重集合计数）+ 代表元去重
- **具体知识点**：给每个「飞机」取唯一代表元 (a, b ≤ c)；固定 a 后的贡献 C(|T|, 2) + |T4|；用全场统计量 g2 / g4 做 O(1) 修正

## 题意（精简）

「飞机」= 10 张牌，重排后形如 {a,a,a, a+1,a+1,a+1, b,b, c,c}（两个**连续**的三张 + 两个对子，
b、c 可相等、也可与 a/a+1 重合）。两个飞机相同 ⟺ 十张牌的可重集合完全一样。
给 n 张牌的牌面，求能选出多少种不同的飞机，答案对 998244353 取模。

**数据范围**：n ≤ 2×10^5；a<sub>i</sub> ≤ 2×10^5；答案取模 998244353

## 关键点（为什么用这个算法）

1. 直接数"选 10 张牌的方案"会严重重复计数 → 必须给每个飞机取**唯一代表元**：三元组 (a, b ≤ c)。
2. 代表元唯一性的证明（不重不漏的关键）：若同一可重集合还能写成 `(a', b', c')` 且 a' ≠ a，
   则 a' ≥ a+2 时集合里要有 4 种数字各 ≥3 张（≥12 张 > 10），`a' = a+1` 时数字 a+1 要 ≥6 张、
   再加 a、a+2 各 3 张（也是 ≥12 张）——都不可能，所以 a 唯一，b、c 随之唯一。
3. 固定 a 后先扣掉两个三张，容量 cap[x] = cnt[x] − 3 (x ∈ {a, a+1})，其余 `cap[x] = cnt[x]`。
   两个对子分两种情形：b < c 需 cap ≥ 2（从 T = {x : cap[x] ≥ 2} 里挑两个 → C(|T|,2)）；
   b = c 需 cap ≥ 4（T4 = {x : cap[x] ≥ 4} 的大小）。贡献 = C(|T|,2) + |T4|。
4. |T|、|T4| 用全场 g2（够 2 张的数字种数）、g4（够 4 张的数字种数）加修正项 O(1) 得到，
   不必每个 a 重扫 → 总复杂度 O(n + 值域)。修正项要**逐个位置判断**：
   |T4| = g4 − [cnt[a]≥4] − [cnt[a+1]≥4] + [cnt[a]≥7] + [cnt[a+1]≥7]。

## 复杂度

- 时间：O(n + 值域)，值域 2×10^5 + 2
- 空间：O(值域)

## 踩过的坑

1. **修正项想当然写成固定减 2**：|T| = g2 − 2 + … 只在 a、a+1 都够 2 张时成立；
   |T4| = g4 − 2 + … 是错的（样例 1 里 `cnt[2] = 3 < 4`，a+1 根本不在 g4 里，减 2 会少算）。
   正确写法是按 [cnt[a]≥4]、[cnt[a+1]≥4] 逐项判。这个错误是靠**样例 1 手算**（答案是 1 而不是 0）抓出来的。
2. **漏掉 b = c**：样例 1 就是 b = c = 1（七个 1、三个 2），只数两个不同点数会得到 0。
3. b/c 允许等于 a 或 a+1，此时能用的是扣掉三张之后的余量 → 判据是 cnt[a] ≥ 5 而不是 ≥ 2。
4. 用 `int` 存 C(|T|,2) 会溢出（最大到 2×10^10）→ 用 `long long`。
5. 数组要开到值域 + 2（代码里访问 `cnt[a+1]`）。

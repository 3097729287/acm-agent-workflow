# 题目记录模板

> **归档根目录**：`<数据根>\算法\`
> **索引**：`<数据根>\索引\题解算法索引.md`—— 新增一条记录后，跑 `tools\index_sync.py` 同步（别手改表）。
> **用法**：把下面「正文」整段复制成一个新 md，**放进对应的算法文件夹**，文件名 `<比赛名>-<题号>-<题名>.md`。
> 例：`<数据根>\算法\树状数组\牛客周赛Round159-F-小月的路径码.md`
> **固定五节**（顺序不许变，不许加节）：题意（精简）→ 关键点（为什么用这个算法）→ 复杂度 → 踩过的坑 → 相关。本库所有记录都按这五节写（「数据范围」是题意节里的加粗一行）。
> 一题多算法时：**主算法文件夹**放这份详写版；其余算法文件夹的 `题解指针.md` 里加一行（见文末）。
> 编码 UTF-8 无 BOM、行尾 LF；数学写 LaTeX（`$...$`，下标写 `$a_i$`；见知识库《数学 LaTeX》）。
> **难度一律写 CF 数字**（900 / 1100 / 1300 / 1500 / 1800）——
> 不写「入门 / 普及- / 普及 / 普及+ / 提高」这类档位名（用户看不懂），**也不写 AC 数 / 提交数**（那是榜单快照，会变）。

## 附：次要算法的「一行指针」写法

放进**次要**算法文件夹里的 `题解指针.md`。一题一行，**不写标题、不写说明文字、不写完整文件名**：

    行内格式：- <题号> <题名>：`<主算法文件夹>\`
    例子：    - F 小月的路径码：`树状数组\`

只写主算法文件夹的名字，是因为同一道题的主记录文件名自带比赛与题号，翻到那个文件夹就能找到。
一份 `题解指针.md` 里可以有多行（该算法被多少道题当过次要算法就写多少行）。

# 题库（真实题解数据根）

给两类人：想看大家贡献的真场题解长什么样；以及要往这里导包的维护者。这里是**发布用的数据根**，结构与
`demo\` 完全一样（盘上布局见 [README 的「一场跑完，盘上留下什么」](../README.md#一场跑完盘上留下什么)）；`题解\题目状态.md`、`索引\题目记录模板.md` 已随骨架放好。

```text
题库\
├── 题解\牛客周赛\RoundNNN\RoundNNN题解.md   ← 整场题解（每题目录在它旁边）
├── 算法\<算法名>\牛客周赛RoundNNN-X-*.md    ← 算法库记录（五节模板）
├── 索引\题解算法索引.md                     ← 全量索引（反查表 + 场次小节）
└── 知识库\06-题解算法归档.md                ← 归档台账（精简索引 + 算法→文件夹对照表）
```

**为什么这里自带一份 `知识库\`**：台账里的「共 N 条」是对**某一个数据根**说的——仓库的 `knowledge\` 描述示例
`demo\`（CI 的示例闸门按它核对），题库这一份描述题库自己，两个根各算各的账、谁也改不掉谁的数字——所以**往题库导包必须带 `--mem 题库/知识库`**。

## 导包（维护者）

图形端：`status_gui.py --file 题库/题解/题目状态.md` 打开，菜单「题解包 → 导入题解包…」选包，报告里点「应用到数据根」。命令行：

```bash
python tools/import_solution.py <包.zip> --root 题库 --mem 题库/知识库          # dry：先看报告
python tools/import_solution.py <包.zip> --root 题库 --mem 题库/知识库 --apply # 确认后落盘
python tools/archive_check.py RoundNNN --root 题库 --status 题库/题解/题目状态.md --mem 题库/知识库
# ↑ 退出码 0 = 收工
```

## 注意

- `--root` 记得指到 `题库`（或 `install.py --data-root 题库` 之后省掉）；**`--mem 题库/知识库` 也要一起带上**——否则默认动的还是示例 `demo\`、台账也对不上；
- 导入会写文件 / 索引 / 状态表 / 台账四处，写前自动备份（备份落在 `config.json` 的 `backup_root`）；
- 题库是数据根、不是仓库代码：题解归贡献者，按 MIT 发布，署名在各自 manifest 的 `contributor` 里。

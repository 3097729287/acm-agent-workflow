## A. 小红的区间计数

### 题意

给你三个整数 $a, b, c$ 和一段区间 $[l, r]$，问区间里有多少个整数**跟 $a$、$b$、$c$ 三个都不相等**。

### 手算

样例 1：$a=1, b=2, c=3, l=1, r=4$。区间里是 1 2 3 4，其中 1、2、3 各撞上一个，只剩 4 → 答案 1。

### 思路

一句话：**先全算，再把不合格的扣掉**。

区间长度是 $r - l + 1$，这是"候选总数"。不合格的数最多只有 3 个（就是 $a$、$b$、$c$ 本身，而且还得落在区间里）。所以：

```
答案 = (r - l + 1) - （a, b, c 中落在 [l, r] 内、且互不相同的个数）
```

**这里有个小陷阱：$a$、$b$、$c$ 可以相等。** 比如 $a=b=c=1, l=r=1$，长度 1 只能减 1 次，减 3 次就成负数了。所以判断时要"去重"：只看它跟前面已经算过的数是否重复。

### 参考代码

```cpp
// 牛客周赛 Round 140 A - 小红的区间计数
// 思路：区间长度 r-l+1，最多减 3（a,b,c 中落在区间内且互不相同的数）
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long a, b, c, l, r;
    cin >> a >> b >> c >> l >> r;

    long long ans = r - l + 1;      // 区间里的整数总个数
    long long v[3] = {a, b, c};
    for (int i = 0; i < 3; i++) {
        if (v[i] < l || v[i] > r) continue;   // 不在区间里，不影响答案
        bool dup = false;                     // 与前一个重复的话只减一次
        for (int j = 0; j < i; j++)
            if (v[j] == v[i]) dup = true;
        if (!dup) ans--;
    }
    cout << ans << "\n";
    return 0;
}
```

### 易错点

1. **$a$、$b$、$c$ 相等时重复扣**。$a=b=c=1$、区间 [1,1]：正确答案 0，重复扣会得到 -2。官方样例抓不到这个（样例里三个数互不相同），得自己造。
2. 忘了判"在不在区间里"。$a=5$、区间 [1,4]：扣了就错。
3. 类型：$l, r \le 10^9$，$r - l + 1$ 最大 $10^9$，`int` 其实装得下，但这类"区间长度"的题一律写 `long long`，省得下次改题面就溢出。

## B. 小红的牛魔

### 题意

给一个只含 $n/i/u/m/o$ 的串。每次操作可以删掉一个**连续子串** niu 或者 mo，删完两边会接上。可以操作任意次，问能不能把整个串删光。

### 手算

样例 1 niumo：删 niu → 剩 mo → 删 mo → 空 → Yes。

样例 2 omuin：一眼看上去里头的字母 $o, m, u, i, n$ 正好就是 niu + mo 的字母集合，但任何时刻都凑不出相邻的 niu 或 mo → No。

**这两个样例合起来就在提示一件事：光数字母个数是错的。** omuin 的字母多重集和 niumo 完全一样，答案却相反。**相邻关系才是关键**，所以需要一个能表达"相邻"的工具——栈。

### 思路

**核心做法：从左往右扫，用栈当消除机。**

```
对于串里的每个字符 c：
    把 c 压进栈
    如果栈顶 3 个字符是 "niu"  → 弹出这 3 个
    否则如果栈顶 2 个字符是 "mo" → 弹出这 2 个
扫完之后：栈空 = Yes，否则 No
```

用样例走一遍：

| 串 | 栈的变化 | 结论 |
|---|---|---|
| niumo | $n \to ni \to niu \to$空 $\to m \to mo \to$空 | Yes |
| omuin | $o \to om \to omu \to omui \to omuin$ | No |
| niuniu | 第一组 niu 弹光，第二组再弹光 | Yes |
| nniu | $n \to nn \to nni \to nniu$，后缀是 niu → 弹掉，剩 $n$ | No |

最后那个 nniu 值得注意：它确实删掉了一个 niu，但删完之后**剩下一个 $n$ 收不掉**——这就是"能删"和"能删光"的区别。

#### 为什么只看栈顶就够

1. **新模式一定以刚压入的字符结尾。** 压入之前，栈是一个"消不动的"串（下面叫它**不可约**）。压入 $c$ 之后，如果出现了 niu 或 mo，这个模式必然覆盖最后一个字符 $c$（否则它在压入前就存在了，矛盾）。所以只需要检查末尾 2~3 个字符。
2. **弹完之后不用回头再看。** 弹出末尾几个字符后，栈变成了"刚才那个不可约串的一个前缀"。**不可约串的子串当然也不可约**，所以不会再冒出新模式，一次检查就够了。

#### 为什么能消就消的贪心不会把好串删坏

两条规则的字母表是分开的（niu 用 $n/i/u$，mo 用 $m/o$），而且 niu 没有"真前缀 = 真后缀"的自重叠（$n$、ni 都不是 $u$、iu 那种错位能接上的形式），mo 同理。这类"模式之间没有重叠歧义"的删除系统有个好性质：**无论按什么顺序删，删到不能删时剩下的串是唯一的**（术语叫合流性 / 唯一范式）。所以贪心地"见到就删"得到的就是那个唯一的最终形式——它空，iff 原串能删光。

> 反过来说：如果规则换成 aa → 空 这种有自重叠的，或者两条规则共用字母，贪心就未必对了——那时候才需要真去搜索。

### 参考代码

```cpp
// 牛客周赛 Round 140 B - 小红的牛魔
// 思路：删除 "niu" / "mo" 两个模式互不重叠（没有临界对），重写系统合流，
//       所以从左往右用栈「能消就消」，最后看栈是否为空。
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    string s;
    cin >> n >> s;

    string st;                      // 栈：当前的不可约简形式
    st.reserve(n);
    for (char ch : s) {
        st.push_back(ch);
        int m = (int)st.size();
        if (m >= 3 && st[m - 3] == 'n' && st[m - 2] == 'i' && st[m - 1] == 'u') {
            st.resize(m - 3);       // 弹出 "niu"
        } else if (m >= 2 && st[m - 2] == 'm' && st[m - 1] == 'o') {
            st.resize(m - 2);       // 弹出 "mo"
        }
        // 弹出后剩下的还是「不可约」的：它是弹出前栈的前缀，而前缀不可能突然出现新模式
    }
    cout << (st.empty() ? "Yes" : "No") << "\n";
    return 0;
}
```

### 易错点

1. **拿字母计数当判据**。反例就是官方样例 2（omuin），字母全对但顺序不对。
2. **弹出后忘了栈变短**：用 $st.resize(m - 3)$ 而不是 st.pop_back() 三次也行，但千万别写成"标记删除"还继续用旧下标。
3. **$m >= 3 / m >= 2$ 的边界**：$n=1$、串是 $n$ 时（样例里没有，但数据里有）会直接越界访问 `st[-1]`。加了 $m >= 3$ 判断就没问题。
4. 用 `string` 当栈比 `stack<char>` 更顺手：能 resize、能随机访问栈顶几个字符，而且内存连续、更快。$n \le 2 \times 10^5$ 时这点无所谓，但习惯值得养成。

## C. 小红的矩阵计数

### 题意

一个 $n \times m$ 的矩阵，每格是 0/1/2。一个"L 块" = **恰好三个格子**组成的连通块，形状正好是"$2 \times 2$ 方阵里挖掉一格"。问有多少个 L 块，它三个格子上的字符**互不相同**（即 0、1、2 各一个）。

### 手算

样例是 2 行 3 列：

```
0 1 2
2 1 0
```

- 左边那个 $2 \times 2$ 窗口（列 1~2）：格值是 `[[0,1],[2,1]]`
  - 挖左上 → {1,2,1}：1 重复，不行
  - 挖右上 → {0,2,1}：互不相同 ✓
  - 挖左下 → {0,1,1}：不行
  - 挖右下 → {0,1,2}：互不相同 ✓
  - 小计 2 个
- 右边那个 $2 \times 2$ 窗口（列 2~3）：格值是 `[[1,2],[1,0]]` → 同样 2 个（挖右上 {1,1,0}、挖右下 {1,2,1} 不行，另两种行）

合计 2 + 2 = 4，和样例输出一致。

### 思路

#### 关键观察：L 块与「$2 \times 2$ 方阵 + 缺哪一格」一一对应

$2 \times 2$ 的方阵里挖掉任意一格，剩下的三格一定是连通的、形状就是 L 形；反过来，任何一个 L 形都能被唯一地装进一个 $2 \times 2$ 方阵里。所以**数 L 块 = 枚举每个 $2 \times 2$ 窗口 $\times 4$ 种挖法**。

### 参考代码

```cpp
// 牛客周赛 Round 140 C - 小红的矩阵计数
// 思路：每个 L 块 ↔ (某个 2×2 方阵, 缺的那一格)，共 4 种。
//       枚举每个 2×2 窗口的 4 个三元组，判断三个字符是否互不相同。
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<string> g(n);
    for (auto &row : g) cin >> row;

    long long ans = 0;
    for (int i = 0; i + 1 < n; i++) {
        for (int j = 0; j + 1 < m; j++) {
            char a = g[i][j], b = g[i][j + 1];
            char c = g[i + 1][j], d = g[i + 1][j + 1];
            char tri[4][3] = {{a, b, c}, {a, b, d}, {a, c, d}, {b, c, d}};
            for (int k = 0; k < 4; k++) {
                char x = tri[k][0], y = tri[k][1], z = tri[k][2];
                if (x != y && y != z && x != z) ans++;   // 恰好 0、1、2 各一个
            }
        }
    }
    cout << ans << "\n";
    return 0;
}
```

### 易错点

1. **只数了 2 种挖法**。L 形有 4 个朝向（缺口分别在四个角），少写朝向答案就偏小。好在样例 1 的 4 个合格 L 块**恰好把 4 种朝向各覆盖一次**（左窗口缺右上、缺右下，右窗口缺左上、缺左下）——所以这是个样例能当场抓到的错：少写一半会输出 2 而不是 4。
2. **"三个字符互不相同"写成"三个字符的和等于 3"**？0+1+2 = 3，但 0+0+3 不存在（只有 0/1/2），1+1+1 = 3 也等于 3——**这是错的**。要么老老实实两两比较，要么用 `x+y+z == '0'+'1'+'2'`（147，`'1'*3 = 147`；这个等价关系只在字符集是 {0,1,2} 时成立，属于技巧、不建议依赖）。
3. **下标越界**：循环条件写 $i + 1 < n$ 而不是 $i < n$。
4. 答案上限 $(n-1)(m-1) \times 4 \approx 4 \times 10^6$，`int` 够；但用 `long long` 不亏。

## D. 小红的排序（easy）

### 题意

一个 1 ~ $n$ 的排列 $p$，两个正整数 $x$、$y$（本题保证 $x < y \le \lfloor n/2 \rfloor$）。每次操作选一个下标 $i$，做下面两种交换之一：

- 交换 $p_i$ 与 $p_{i+x}$（要求 $i + x \le n$）；
- 交换 $p_i$ 与 $p_{i+y}$（要求 $i + y \le n$）。

问能不能排成 $[1, 2, \ldots, n]$。

### 手算

- 样例 1 的 $n=4, x=1, y=2$：$x=1$ 连出 1-2, 2-3, 3-4，$y=2$ 连出 1-3, 2-4 → 整张图连通成一个块。排列 2 3 1 4 里 1,2,3 都在这个块里 → **Yes** ✓
- 样例 1 的 $n=8, x=2, y=4$：$x=2$ 连 1-3, 2-4, 3-5, 4-6, 5-7, 6-8；$y=4$ 连 1-5, 2-6, 3-7, 4-8。结果是**两个块**：奇数位 {1,3,5,7} 和偶数位 {2,4,6,8}（因为步长都是偶数，奇偶永远换不了）。排列是 1 8 7 4 6 3 2 5，值 2 停在位置 7（奇数块），而它该去的位置 2 在偶数块 → **No** ✓

第二个例子就是"为什么不能只看图连不连通"的活例子：这题的图**可以不连通**。

### 思路

#### 第一步：把交换数组里的值翻译成交换位置

这是本题最重要的一步思想转换。$p_i$ 和 $p_{i+x}$ 交换，本质上是**位置 $i$ 和位置 $i+x$ 上的东西对调**。至于那两个位置上装的是几，跟"能不能换"无关——能不能换只看 $i$ 和 $i+x$ 的位置关系。

所以把所有位置 $1 \ldots n$ 看成一张图的点，对每个合法的 $i$ 连一条边 $i$ — $i+x$，再对每个合法的 $i$ 连一条边 $i$ — $i+y$。**能互相交换的两个位置之间连边**，得到的每个连通块内部，位置之间可以任意重排（因为"对换"能生成整个对称群：同一连通块里任意两个位置都能通过一连串对换把东西换过去）。

#### 第二步：判断标准

最终目标里，值 $v$ 要待在位置 $v$。所以：

```
可行  ⟺  对每个值 v，v 当前所在的位置 p[v] 与位置 v 属于同一个连通块
```

（`p[v]` 是"位置 $v$ 上的值"；由于 $p$ 是排列，"值 $v$ 现在在哪"和"位置 $v$ 上是哪个值"说的是同一件配对关系，两种写法等价——证明一句话：设 $\sigma$ 是位置→值的映射，条件 $f(\sigma^\{-1\}(v)) = f(v)$ 与 $f(v) = f(\sigma(v))$ 对全体 $v$ 成立是同一件事。）

复杂度：每组 $O(n \alpha(n))$，全体 $O(\sum n \cdot \alpha)$。

### 参考代码

```cpp
// 牛客周赛 Round 140 D - 小红的排序（easy）
// 思路：交换操作是「位置 i 与位置 i+x / i+y」的对换，能生成每个连通分量内的任意置换。
//       并查集维护位置图；可排序 <=> 每个值 v 的当前位置 p[v] 与 v 同属一个分量。
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> f;
    explicit DSU(int n) : f(n + 1) {
        iota(f.begin(), f.end(), 0);
    }
    int find(int x) {                 // 迭代 + 路径减半，别写递归
        while (f[x] != x) {
            f[x] = f[f[x]];
            x = f[x];
        }
        return x;
    }
    void unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a != b) f[a] = b;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int n, x, y;
        cin >> n >> x >> y;
        vector<int> p(n + 1);
        for (int i = 1; i <= n; i++) cin >> p[i];

        DSU d(n);
        for (int i = 1; i + x <= n; i++) d.unite(i, i + x);
        for (int i = 1; i + y <= n; i++) d.unite(i, i + y);

        bool ok = true;
        for (int v = 1; v <= n; v++) {
            if (d.find(v) != d.find(p[v])) {   // 值 v 最终要落在位置 v 上
                ok = false;
                break;
            }
        }
        cout << (ok ? "Yes" : "No") << "\n";
    }
    return 0;
}
```

### 易错点

1. **忘了 $i + x \le n$ 这个约束**。$x$ 可以接近 $n$，那时只有 $i = 1$ 能换。直接 $1..n$ 全连边会多连出一堆假边（尤其坑 E 题）。
2. **判断方向写反**：是"值 $v$ 现在待的位置"要和"位置 $v$"同块。用当前位置数组 `pos[value] = 下标` 时最容易抄反，一旦反了，样例 1 的第二组（No）立刻变 Yes——所以样例能抓到这个错。
3. **find 写成递归**。这份并查集没有按秩合并（只有路径减半），最坏情况下树可以很深（$n = 2 \times 10^5$），递归版有爆栈风险。实测同类题的实测记录：递归 dfs 在 $2 \times 10^5$ 的链上直接 0xC00000FD。**一律写迭代版**。
4. **多组数据没清空**：T 到 $2 \times 10^4$，每组都要按当组的 $n$ 重新建 DSU。别用全局数组只清 $1..n$（$n$ 变小后旧数据会残留）。

## E. 小红的排序（hard）

### 题意

跟 D 唯一的区别是约束：D 保证 $x, y \le \lfloor n/2 \rfloor$，E 只保证 $x, y < n$（$4 \le n \le 2 \times 10^5$，$1 \le x < y < n$，单个测试文件 $\sum n \le 2 \times 10^5$）。

### 手算

```
2
4 1 2
4 3 2 1
5 2 4
1 3 2 4 5
```

- 第一组 $n=4, x=1, y=2$：跟 D 一样全连通，4 3 2 1 可以整个翻过来 → Yes ✓
- 第二组 $n=5, x=2, y=4$：$x=2$ 连 1-3, 2-4, 3-5；$y=4$ 连 1-5。于是 {1,3,5} 一块、{2,4} 一块。排列 1 3 2 4 5 里，值 2 在位置 3（属于 {1,3,5} 块），但位置 2 在 {2,4} 块 → **No** ✓

### 思路

#### 这题的难在哪、又不在哪

- **不在算法上**：并查集的建边规则一字不改——还是 $i$ — $i+x$（$i+x \le n$ 时）和 $i$ — $i+y$（$i+y \le n$ 时）。$x$ 或 $y$ 超过 $n/2$ 只是让边**变少**，$i + x \le n$ 这个条件本来就在代码里，**D 的代码直接交 E 就能过**。
- **在思路上**：easy 版多了 $x, y \le \lfloor n/2 \rfloor$ 这个额外保证，容易让人以为"图一定连通""有某种整除结构"，于是写一个只在 easy 成立的判据（比如"看 `gcd(x, y)` 分几类"）。这个若明若暗的规律在 E 里不成立，就成了 D 过 E 挂。

所以本篇**只给一套解法、贴两份代码**：`E.cpp` 与 `D.cpp` 的**可执行部分完全相同**（去掉注释和空行后 44 行逐字一致），只有注释措辞不同（E 的注释多写了一句"hard 版差在哪"）。这不是偷懒——**正确的做法本来就是一套**：把"能换哪些位置"老老实实建成图，连通块内任意重排，再看每个值在不在自己该在的块里。建边是 $O(n)$，$\sum n \le 2 \times 10^5$ 完全够。

### 参考代码

（`E.cpp` 的可执行部分与 `D.cpp` 完全相同，只有注释措辞不同——正确的做法本来就是一套。）

```cpp
// 牛客周赛 Round 140 E - 小红的排序（hard）
// 思路：与 easy 完全同一套做法——交换能力等价于「位置图每个连通分量内可任意重排」，
//       并查集维护位置图，判每个值 v 的当前位置 p[v] 是否与 v 同分量。
//       差别只在约束（本题 x,y < n，可换的对更少），算法不变，O(n α(n))。
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> f;
    explicit DSU(int n) : f(n + 1) {
        iota(f.begin(), f.end(), 0);
    }
    int find(int x) {
        while (f[x] != x) {
            f[x] = f[f[x]];
            x = f[x];
        }
        return x;
    }
    void unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a != b) f[a] = b;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int n, x, y;
        cin >> n >> x >> y;
        vector<int> p(n + 1);
        for (int i = 1; i <= n; i++) cin >> p[i];

        DSU d(n);
        for (int i = 1; i + x <= n; i++) d.unite(i, i + x);
        for (int i = 1; i + y <= n; i++) d.unite(i, i + y);

        bool ok = true;
        for (int v = 1; v <= n; v++) {
            if (d.find(v) != d.find(p[v])) {
                ok = false;
                break;
            }
        }
        cout << (ok ? "Yes" : "No") << "\n";
    }
    return 0;
}
```

### 易错点

1. 把 $x$、$y$ 当"值的差"而不是"下标的差"——本题交换的是**下标**。
2. 在 E 上套 D 的"特殊结构"假设（例如认为块数等于某个 `gcd`）——实测随机对拍里已经出现过"两个块"的 $n=8, x=2, y=4$，以及"块数看似和 `gcd` 有关但其实还受 $i+x \le n$ 限制"的情况。**只信建图 + 并查集，不信规律。**
3. T 组数据里单组 $n$ 小、总和 $2 \times 10^5$：别对每组重新 $O(n)$ 清空大数组到 $2 \times 10^5$（$T = 2 \times 10^4$ 时会变成 $4 \times 10^9$ 次操作）。按当组 $n$ 建 `vector` 就没这问题。

## F. 小红的三角形构造

### 题意

给正整数 $x$（$x \le 10^9$），要你造一个**非退化**的直角三角形（三边都是正整数、任意两边之和大于第三边），要求**至少有一条边恰好等于 $x$**。三边输出上限 $9 \times 10^{18}$。存在就输出 Yes + 三个整数，不存在输出 No。多解任意（Special Judge）。

### 手算

样例：$x = 1 \to No$；$x = 3 \to$ 公式一给 $b = (9-1)/2 = 4$、$c = 5$，即 (3, 4, 5) ✓。

> **注意**：本题官方样例的输出**恰好就是** 3 4 5，本篇的公式给出的是同一个答案。这在 Special Judge 构造题里要专门说一句——**样例不是唯一解**，判题只看三个数是否构成合法三角形且含 $x$。反过来说，本地自测时别拿"和样例一模一样"当通过标准（可本题的 $x=1$ 那组还真的是 No，两组都对得上）。

### 思路

#### 从零推导：直角边是 $x$ 时怎么找另外两条边

设直角边是 $x$ 和 $b$，斜边是 $c$。勾股定理：

```
b² + x² = c²   ⟹   c² - b² = x²   ⟹   (c - b)(c + b) = x²
```

这一步是整道题的钥匙：**把"找两条边"变成"把 $x^2$ 拆成两个因子"**。设 $c - b = d$、$c + b = x^2/d$，那么

```
b = (x²/d - d) / 2,      c = (x²/d + d) / 2
```

只要 $d$ 和 $x^2/d$ **同奇偶**，$b$、$c$ 就是整数；要 $b > 0$，就要 $d < x^2/d$。

**情况一：$x$ 是奇数。** $x^2$ 是奇数。取最小的因子对 $d = 1$、$x^2/d = x^2$，两者都是奇数、同奇偶 ✓。于是：

```
b = (x² - 1) / 2,      c = (x² + 1) / 2
```

即 $(x, (x^2-1)/2, (x^2+1)/2)$。验证：`((x²+1)/2)² - ((x²-1)/2)² = [(x²+1)² - (x²-1)²] / 4 = (4x²)/4 = x²` ✓

**情况二：$x$ 是偶数。** $x^2$ 是 4 的倍数。$d = 1$ 不行（1 和 $x^2$ 一奇一偶，$b$ 会是半整数）。取最小的同奇偶因子对 $d = 2$、$x^2/d = x^2/2$（都是偶数 ✓），于是：

```
b = (x²/2 - 2) / 2 = x²/4 - 1,      c = (x²/2 + 2) / 2 = x²/4 + 1
```

注意 $x^2/4 = (x/2)^2$，所以写成 $(x, (x/2)^2 - 1, (x/2)^2 + 1)$ 更好算：

| $x$ | $x/2$ | $b = (x/2)^2 - 1$ | $c = (x/2)^2 + 1$ | 三角形 |
|---|---|---|---|---|
| 4 | 2 | 3 | 5 | 4, 3, 5 ✓ |
| 6 | 3 | 8 | 10 | 6, 8, 10 ✓ |
| 8 | 4 | 15 | 17 | 8, 15, 17 ✓ |
| 10 | 5 | 24 | 26 | 10, 24, 26 ✓ |

#### 那两个无解的 $x$ 怎么看出来

- $x = 1$：$(c-b)(c+b) = 1$，只能是 $c-b = c+b = 1 \to b = 0$，不是三角形。$x = 1$ 当斜边也不可能：$a^2 + b^2 \ge 1 + 1 = 2 > 1 = x^2$。
- $x = 2$：$(c-b)(c+b) = 4$，因子对只有 $(1, 4)$（一奇一偶，$b$ 非整数）和 $(2, 2)$（$b = 0$）→ 无解。当斜边也不行：$a^2 + b^2 = 4$ 的正整数解不存在（最小的 1 + 1 = 2，下一个 1 + 4 = 5 已经超过 4）。

而 $x \ge 3$ 时，奇数走公式一、偶数走公式二，**永远有解**。

### 参考代码

```cpp
// 牛客周赛 Round 140 F - 小红的三角形构造
// 思路：x 当直角边。
//   x 为奇数 (x>=3)：x² = ((x²+1)/2)² - ((x²-1)/2)²，取 (x, (x²-1)/2, (x²+1)/2)
//   x 为偶数 (x>=4)：x² = ((x/2)²+1)² - ((x/2)²-1)²，取 (x, (x/2)²-1, (x/2)²+1)
// x = 1、2 无解（枚举 (c-b)(c+b)=x² 的因子对可证），其余都有解。
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        long long x;
        cin >> x;
        if (x <= 2) {
            cout << "No\n";
            continue;
        }
        long long a = x, b, c;
        if (x & 1LL) {
            long long h = (x * x - 1) / 2;   // x² ≤ 10^18，long long 装得下
            b = h;
            c = h + 1;
        } else {
            long long h = x / 2;
            h = h * h;
            b = h - 1;
            c = h + 1;
        }
        cout << "Yes\n" << a << " " << b << " " << c << "\n";
    }
    return 0;
}
```

### 易错点

1. **$x = 1$、2 直接套公式**：$x = 1$ 会算出 $b = 0$（非法边长），$x = 2$ 会算出 $(x^2-1)/2$ 不是整数。必须特判输出 No。
2. **$x$ * $x$ 用 `int`**：$x$ 到 $10^9$，$x^2$ 到 $10^{18}$，`int` 直接溢出成垃圾——**这个官方样例抓不到**（样例的 $x$ 很小），得自己造 $x=10^9$。中间量一律 `long long`（$9.22 \times 10^{18}$ 的上限刚好够）。
3. **奇偶分支搞混**：偶数分支里是 $(x/2)^2$，不是 $x^2/2$；奇数分支里 $(x^2-1)/2$ 与 $(x^2+1)/2$ 是**相邻整数**，$c = b + 1$ 是最省事的写法。
4. **Special Judge 提醒**：本题多解，牛客的"自测运行"可能对着一份**固定答案**比，于是把你的正确答案判错。**本地自己验**：$\min(a, b, c) \ge 1$、三边排序后 $p^2 + q^2 = r^2$、且 $x$ 在其中。当时那个检查器（`check_F_out()`）已随工作目录清理删除，逻辑就是上面这三个条件，二十行就能重写。

## G. 小红的生成树构造

### 题意

$n$ 个点 $m$ 条边的无向**连通**图，每个点有一个标记 A/B/C/D。要你找一棵**生成树**，满足四条要求（其实就是两组）：

- 每个 A 点：存在一条从它出发、**不经过任何 C 或 D 点**的路径，通到某个 B 点；
- 每个 B 点：同理，不经过 C/D，通到某个 A 点；
- 每个 C 点：存在一条从它出发、**不经过任何 A 或 B 点**的路径，通到某个 D 点；
- 每个 D 点：同理，不经过 A/B，通到某个 C 点。

有解输出 Yes + n-1 条边（顺序任意，Special Judge），无解输出 No。

### 手算

**样例 1**：$n=4$，标记 ABCD，图是 1-2-3-4-1 的环。

- S1 = {1(A), 2(B)}：它们之间有边 1-2 → 分量 {1,2}，含 A 和 B ✓
- S2 = {3(C), 4(D)}：有边 3-4 → 分量 {3,4}，含 C 和 D ✓

→ Yes。官方给的树是 1-2, 1-4, 4-3：S1 内部只剩 1-2 ✓，S2 内部只剩 4-3 ✓，跨组边 1-4 把两块连起来 ✓，共 3 条边 ✓。

**样例 2**：$n=4$，标记 ACBD，图是一条链 1-2-3-4。

- S1 = {1(A), 3(B)}：1 和 3 之间**没有直接边**（1 只连 2，2 是 C）→ `G[S1]` 是两个分量 {1} 和 {3}，其中 {1} 只有 A、{3} 只有 B → **不满足条件** → No ✓

这正是本题最容易错的直觉：**"图里 A 和 B 都有"是不算数的，得看它们能不能只用 A/B 点互相够到。**

**样例 3**：$n=10$，标记 AACDBDDBDB（即 1A 2A 3C 4D 5B 6D 7D 8B 9D 10B）。

- S1 = {1,2,5,8,10}：边 1-2, 1-5, 1-8, 1-10 把它们连成一块，含 $A(1, 2)$ 与 B(5,8,10) ✓
- S2 = {3,4,6,7,9}：边 3-4, 3-6, 3-7, 3-9（还有 4-1、4-2、6-1 等跨组边不算）连成一块，含 C(3) 与 D(4,6,7,9) ✓

→ Yes。官方给的树里，S1 内部用了 1-5, 5-2, 2-8, 1-10 四条（4 个点的森林 ✓），S2 内部用了 4-3, 3-6, 3-7, 3-9 四条（5 个点的森林 ✓），跨组边只有 1-4 一条，合计 $9 = n-1$ ✓。

### 思路

#### 第一步：把四条要求翻译成子图连通块的话

先看前两条。从 A 点到 B 点、路上不许踩 C/D，说明**这条路径上的每个点都是 A 或 B**。这些点和边都在"只保留 A/B 点及它们之间的边"的那个子图里——记作 `G[S1]`，其中 S1 = {A 点$\} \cup \{B$ 点}。

关键：**在生成树里，这两个点之间的路径必须整个待在 S1 内**。于是前两条要求等价于：

> 生成树里，把 S1 的点单独拎出来（连同树中两端都在 S1 的边），得到的**每个连通块里都至少有 1 个 A 和 1 个 B**。

（"至少 1 个 A 和 1 个 B"是充分的：同块内任意两点之间在树里的路径不跑出这个块。也是必要的：某个 A 点要通到某个 B 点，那个 B 必然和它在同一个块里。）

后两条同理，换成 S2 = {C 点$\} \cup \{D$ 点}，要求**每个连通块里都至少有 1 个 C 和 1 个 D**。

#### 第二步：为什么看图 `G[S1]` 的分量就够了

生成树 T 的边是原图 G 的边的子集，所以 T 在 S1 内部的连通性只可能**比 `G[S1]` 更碎**：T 里 S1 的每个块都装在 `G[S1]` 的某个分量里。于是必要性升级成一个只看原图的条件：

> **`G[S1]` 的每个连通分量里都至少有 1 个 A 和 1 个 B；`G[S2]` 的每个连通分量里都至少有 1 个 C 和 1 个 D。**

**而它也是充分的**——下面直接给出构造，顺便就把充分性证了。

#### 第三步：构造（三段式）

1. **组内建森林**：对 `G[S1]` 的每个分量取一棵生成树（只用两端都在 S1 的边），对 `G[S2]` 同理。现在得到一片森林，每个连通块就是 `G[S1]` / `G[S2]` 的一个分量，**块内的字母构成正好满足要求**（条件已经保证了）。
2. **缩点**：把每个"块"缩成一个新点。新图 H 里，原图中**跨组的边**（一端在 S1、一端在 S2）变成 H 里的边。**G 连通 $\implies H$ 连通**：拿 G 里任意一条路径，按"进入/离开某个块"分段，就得到 H 里的一条通路。
3. **在 H 上取生成树**：BFS 或 DFS 都行，每认领一个新点就把对应的那条原图边加进答案。

最后检查边数：组内边 $n$ - (块数) 条 + 跨组边 (块数 - 1) 条 = $n - 1$ 条，而且图连通 → **就是一棵生成树**。又因为组内边只连接同一组的点，跨组边不影响"S1 诱导出的连通块"，所以 S1 的块划分保持为第一步的样子 → 要求全部满足。

复杂度：$O(n \alpha(n) + m)$。

#### 为什么这样构造是对的

1. 必要性：任何合法生成树里，S1 的每个块都要含 A 和 B，而块只会比 `G[S1]` 的分量更碎，所以要原图的每个分量都含 A 和 B；S2 同理。
2. 充分性：按上面三段式构造出的正好是一棵 $n-1$ 条边的连通图，且 S1/S2 的块划分就是 `G[S1]`/`G[S2]` 的分量。
3. 判定与构造共用一个并查集，判完直接用，不用重算。

### 参考代码

```cpp
// 牛客周赛 Round 140 G - 小红的生成树构造
// 结论：可行 <=> 「只由 A/B 点组成的每个连通块里 A、B 都有」且「只由 C/D 点组成的每个连通块里 C、D 都有」。
// 构造：组内边（A-B 之间 / C-D 之间）用并查集取生成森林，缩点后在「跨组边」上 BFS 取生成树。
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> f;
    explicit DSU(int n) : f(n + 1) { iota(f.begin(), f.end(), 0); }
    int find(int x) {
        while (f[x] != x) {
            f[x] = f[f[x]];
            x = f[x];
        }
        return x;
    }
    void unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a != b) f[a] = b;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    string s;
    cin >> s;                                   // s[v-1] 是 v 号点的标记

    vector<int> eu(m), ev(m);
    for (int i = 0; i < m; i++) cin >> eu[i] >> ev[i];

    // 第 0 组 = A/B，第 1 组 = C/D
    auto grp = [&](int v) { return (s[v - 1] == 'A' || s[v - 1] == 'B') ? 0 : 1; };
    // 每组里的「前一半字母」：A/B 组的 A，C/D 组的 C
    auto first = [&](int v) { return (s[v - 1] == 'A' || s[v - 1] == 'C') ? 1 : 2; };

    DSU d(n);
    vector<pair<int, int>> ans;

    // ① 组内边：取生成森林
    for (int i = 0; i < m; i++) {
        if (grp(eu[i]) == grp(ev[i]) && d.find(eu[i]) != d.find(ev[i])) {
            d.unite(eu[i], ev[i]);
            ans.push_back({eu[i], ev[i]});
        }
    }

    // ② 每个组内连通块必须同时含「前一半」和「后一半」字母
    vector<int> mask(n + 1, 0);
    for (int v = 1; v <= n; v++) mask[d.find(v)] |= first(v);
    for (int v = 1; v <= n; v++) {
        if (mask[d.find(v)] != 3) {             // 只有 A 没 B（或只有 C 没 D）
            cout << "No\n";
            return 0;
        }
    }

    // ③ 缩点：并查集分量 -> 新点，跨组边建图
    vector<int> id(n + 1, -1);
    int cnt = 0;
    for (int v = 1; v <= n; v++) {
        int r = d.find(v);
        if (id[r] == -1) id[r] = cnt++;
    }
    vector<vector<pair<int, int>>> cadj(cnt);
    for (int i = 0; i < m; i++) {
        if (grp(eu[i]) != grp(ev[i])) {
            int a = id[d.find(eu[i])], b = id[d.find(ev[i])];
            cadj[a].push_back({b, i});
            cadj[b].push_back({a, i});
        }
    }
    vector<char> vis(cnt, 0);
    vector<int> q;
    q.push_back(id[d.find(1)]);
    vis[q[0]] = 1;
    for (size_t h = 0; h < q.size(); h++) {     // BFS 取缩点图的生成树
        int u = q[h];
        for (auto &pr : cadj[u]) {
            int v = pr.first, ei = pr.second;
            if (!vis[v]) {
                vis[v] = 1;
                q.push_back(v);
                ans.push_back({eu[ei], ev[ei]});
            }
        }
    }

    cout << "Yes\n";
    for (auto &e : ans) cout << e.first << " " << e.second << "\n";
    return 0;
}
```

### 易错点

1. **判定写成"整张图里 A、B 都有"**。样例 2 就是反例：A、B 都在，但 `G[S1]` 里它们不在一个分量 → 应当是 No。
2. **组内边 union 时把跨组边也 union 了**。一旦混进去，掩码会把两组合起来算，条件就永远满足（或永远不满足），判定直接失效。判断条件：`grp(u) == grp(v)`。
3. **缩点之后只连了一条跨组边**：H 里有多个块时必须 BFS 连成一棵树，只加一条边会导致图不连通、边数也不足 $n-1$——**这个官方样例抓不到**（样例 3 的图比较稠密，很容易碰巧连对）。
4. **忘了 No 的时候什么都别输出**（不能先 Yes 再反悔）。
5. **$n = 2$ 之类的小数据**：$n \ge 2$，$m \ge 1$，G 连通。两个点若一个是 A 一个是 C，答案就是 No（本文特殊用例里专门测了）。
6. **Special Judge**：同上，输出顺序任意，但必须是**原图里的边**、恰好 $n-1$ 条、且构成生成树（不自测的话很容易输出一条不存在的边）。

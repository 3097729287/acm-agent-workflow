# 牛客周赛 Round 140 C - 小红的矩阵计数

- **难度**：CF 900
- **原题链接**：https://ac.nowcoder.com/acm/contest/132940/C
- **题解位置**：`题解\牛客周赛\Round140\Round140题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\枚举\`
- **数据结构与算法**：枚举（固定窗口枚举 / 网格枚举）
- **具体知识点**：L 块与"2×2 方阵 + 缺哪一格"一一对应（4 种朝向）；"三字符互不相同"用两两比较

## 题意（精简）

n × m 的矩阵，每格是 0/1/2。定义「L 块」为**恰好三格**组成的连通块，形状正好是 2×2 方阵里挖掉一格。
求有多少个 L 块，它三个格子上的字符**互不相同**（即 0、1、2 各一个）。

**数据范围**：2 ≤ n, m ≤ 1000（nm ≤ 10^6）。

## 关键点（为什么用这个算法）

1. 每个 L 形都能被唯一地装进一个 2×2 方阵、并对应唯一的"缺格"，所以**数 L 块 = 枚举每个 2×2 窗口 × 4 种挖法**。
2. 窗口数 (n-1)(m-1) ≤ 10^6，每窗口 4 次判定常数极小，O(nm) 暴力就够——本题不需要前缀和之类优化。
3. 答案上限 4(n-1)(m-1) ≈ 4×10^6，`int` 装得下（但代码里用 `long long` 不亏）。

## 复杂度

- 时间：O(nm)，10^6 个窗口 × 4 次判定（实测 14 ms）
- 空间：O(nm) 存矩阵（也可边读边做，但没必要）

## 踩过的坑

1. **只数了 2 种朝向** → L 形有 4 种缺口位置，漏一半答案直接差一倍。官方样例里 4 个合格 L 块刚好都在同一行，更容易让人以为只有两种。
2. **用"三数之和"判互不相同** → 错。0+1+2 = 3，但 1+1+1 也等于 3，这个三元组并不互异；换成 ASCII 码相加也一样（`'0'+'1'+'2' = '1'*3 = 147`，但字符串 111 同样得到 147）。**和相等推不出互异**，老老实实写 `x != y && y != z && x != z`。
3. **窗口边界**：循环条件写 i + 1 < n，别写 i < n 之后又去访问 `g[i+1]`。

# 牛客周赛 Round 163 G - 小月的环

- **难度**：CF 1800
- **原题链接**：https://ac.nowcoder.com/acm/contest/140737/G
- **题解位置**：`题解\牛客周赛\Round163\Round163题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\树状数组\`
- **数据结构与算法**：置换环 + 前缀和与差分 + 树状数组 + 二分查找
- **具体知识点**：置换环把"一组"压成区间 [mn, mx]；固定右端点后合法左端点是一段前缀（可二分上界）；答案要 `long long`（可达 n(n+1)/2 ≈ 2×10^10）

## 题意（精简）

n 个房间，传送门是排列 p（从 i 能到 p<sub>i</sub>）；"同一组" = 能通过传送门互相到达的房间，也就是置换的环。
整数 i "穿过"一组 {a<sub>1</sub>,…,a<sub>m</sub>} 当且仅当 min ≤ i < max（左闭右开，单点组永不被穿过）；w<sub>i</sub> 是 i 穿过的组数（i 取 0..n）。
区间 [l,r] "包含"一组当且仅当 l ≤ min 且 max ≤ r，s(l,r) 是它包含的组数。
求 1 ≤ l ≤ r ≤ n 中满足 w<sub>l−1</sub> + w<sub>r</sub> = k 且 s(l,r) ≥ t 的区间个数。

**数据范围**：0 ≤ k, t ≤ n；原文实测按 n = 2×10^5 做极限测试

## 关键点（为什么用这个算法）

1. 后面的条件只用到每组的 `min` 和 `max`，所以先沿 p 走完每个置换环，把一组压成一个闭区间 [mn, mx]。
2. w<sub>i</sub> = #{组 : mn ≤ i &lt; mx} 就是"多少个区间覆盖了点 i"，用差分：每组在 `mn` 处 +1、在 `mx` 处 −1，再前缀和得到 `w[0..n]`。
3. 换字母 L = l−1、R = r，两个条件变成 w<sub>L</sub> + w<sub>R</sub> = k 和 #{组 : mn > L 且 mx ≤ R} ≥ t。
4. 全题最关键的转化：固定 R 后，"已完成组（mx ≤ R）里满足 `mn > L` 的个数"关于 L 单调不增，所以合法 L 是 [0, P] 这样一段前缀；把已完成组的 `mn` 降序排，就有 P = min(R−1, m<sub>t</sub> − 1)（m<sub>t</sub> 是第 t 大的 `mn`）。
5. 统计：固定 R 时条件一要求 w<sub>L</sub> 恰为 k − w<sub>R</sub>，把每个取值对应的所有 L 收进有序数组，答案加上该数组中 ≤ P 的个数（一次 `upper_bound`）。
6. 动态维护第 t 大的 `mn`：R 递增时按 `mx` 分桶把新组加进来，用树状数组统计 `mn` 的分布（值域 1..n），第 t 大 = 第 c − t + 1 小，在树状数组上二分 O(log n)。

## 复杂度

- 时间：找环 O(n)、差分求 w O(n)，每个 R 一次树状数组二分和一次 `upper_bound`，共 O(nlog n)；n = 2×10^5 时是几百万次操作（原文实测 103 ms）
- 空间：O(n)（w、分桶、`pos`、树状数组）

## 踩过的坑

1. 两个不等号抄成一个 → "穿过"是 min ≤ i < max（左闭右开），"包含"是 l ≤ min 且 max ≤ r（闭区间），方向不一致，一错就全错。
2. 把 `mn > L` 写成 mn ≥ L → 因为 l = L + 1，l ≤ mn 就是 `mn > L`，差一位；样例都过不了，但很可能过掉手造的小数据。
3. t = 0 没特判 → 会去查"第 0 大"，`kth(0)` 行为异常；此时 s ≥ 0 恒成立，只剩下上界 P = R−1。
4. 答案用 `int` → 区间总数可达 n(n+1)/2 ≈ 2×10^10（实测 n = 2×10^5、全为单点组、k = 0、t = 100000 时答案为 5000150001），必须 `long long`。

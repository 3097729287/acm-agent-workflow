# 牛客周赛 Round 124 C - 夜揽星河入梦

- **难度**：CF 1500
- **原题链接**：https://ac.nowcoder.com/acm/contest/126120/C
- **题解位置**：`题解\牛客周赛\Round124\Round124题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\连续段\`
- **数据结构与算法**：连续段（数轴上连续的一段）+ 排序扫描
- **具体知识点**：连续段的两种变化（接长 / 合并）；「m 子连珠 ⟺ 长度 m 的连续格子」

## 题意（精简）

一维棋盘上有 n 个黑色棋子，第 i 个坐标是 a<sub>i</sub>，坐标互不相同。若存在 m 个棋子，坐标排序后构成**公差为 1** 的等差数列，称局面出现 m 子连珠。初始局面保证没有 m 子连珠，问**再下一个棋子**（任意整数坐标）能否让局面出现 m 子连珠。多组数据。

**数据范围**：T ≤ 10<sup>4</sup>；n ≤ 2 × 10<sup>5</sup>，m ≤ 10<sup>9</sup>，a<sub>i</sub> ≤ 10<sup>9</sup>，单文件 Σn ≤ 2 × 10<sup>5</sup>；限时 1 秒。

## 关键点（为什么用这个算法）

1. 题面把公差写死成 1，而坐标互不相同且都是整数 ⟹ 「公差 1 的等差数列」的 m 个坐标恰好是 x, x+1, …, x+m−1 这 m 个**连续格子**。于是 m 子连珠 ⟺ 存在长度 m 的连续段被占满。
2. 朴素做法（枚举落点 × 枚举窗口）是 O(值域 × n)，值域 10<sup>9</sup>，直接爆。
3. 关键观察：**加一个棋子对「连续段」只有两种作用** —— 贴在某段头尾（该段 +1）、或落进一个恰好 1 格宽的空隙把两段焊起来（左 + 1 + 右）。两种作用都只是"把某一段变长"，不会凭空造段。所以只要数最长连续段 L，答案就是 L + 1 >= m。
4. 这一概念（连续段 = 数轴上连续的一段）与 Round 123 E/F 的"顺子"是同一个结构，题解里只给了指针、没有重讲。

## 复杂度

- 时间：每组 O(n log n)（排序）+ O(n)（扫描）；Σn ≤ 2 × 10<sup>5</sup>，实跑极限 0.021 s
- 空间：O(n)（存坐标数组）

## 踩过的坑

1. **m 要开 `long long`**：m 能到 10<sup>9</sup>，n 却只有 2 × 10<sup>5</sup>，读进来那一步就得 64 位（`int` 直接读错值）。
2. **最长连续段的初值必须是 1**：n ≥ 1，至少一个棋子，段长至少 1；写 0 会在 n = 1 时出错。
3. **别把"公差 1"推广成"公差任意"**：题面写死公差为 1，自己推广就变成另一个题（那题要判的是等间距而非连续）。
4. **对拍时注意暴力的值域**：本题的暴力实现（摊开棋盘逐格试）必须把坐标压在小范围（1..40）才等价；放到大值域上它会判错（实测 3 组不一致，错的是暴力不是正解）。这类"暴力本身有前提"的情况，收窄生成器的值域，别去改正解。

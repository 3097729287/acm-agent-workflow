# 牛客周赛 Round 123 F - 小红出牌（hard）

- **难度**：CF 1500
- **原题链接**：https://ac.nowcoder.com/acm/contest/125954/F
- **题解位置**：`题解\牛客周赛\Round123\Round123题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\连续段\`（本场新建）
- **数据结构与算法**：连续段（差分和公式）+ 增量更新
- **具体知识点**：`最少顺子数 = Σ_v max(0, cnt[v] − cnt[v−1])`；加一张牌只改动 term(v)、term(v+1) 两项

## 题意（精简）

与 E 题**只差一句**：本题**不保证**牌面数字互不相同。其余完全一样——
对每个前缀求"全部出成顺子"的最少次数，输出 n 个答案。

**数据范围**：n ≤ 10^5；a<sub>i</sub> ≤ n（可有重复）

## 关键点（为什么用这个算法）

1. 有重复时"数连续段"不够用（一个顺子里同一数字只能出现一次），换成数**每张牌属于哪个顺子**：
   设 `cnt[v]` 为数字 v 的张数（`cnt[0] = 0`），答案是 `Σ_v max(0, cnt[v] − cnt[v−1])`。
2. 下界：每个顺子最多经过 v−1 一次，所以数字 v 处最多有 `cnt[v−1]` 个顺子是"从左边延伸过来"的，
   剩下的 `cnt[v] − cnt[v−1]` 个必须以 v 为最小数字**开头**；每个顺子恰有一个开头 → 求和是下界。
   可达：按"能接上左边就接上"的贪心配对即可达到。
3. 要对每个前缀回答 → **增量更新**：`cnt[v]` 一变只有 `term(v) = max(0, cnt[v]−cnt[v−1])` 和
   `term(v+1) = max(0, cnt[v+1]−cnt[v])` 两项会动，记下旧值、`cnt[v]++`、再算新值，总和加上差值。
   每步 O(1)，总 O(n)。

## 复杂度

- 时间：O(n)
- 空间：O(n)（计数数组）

## 踩过的坑

1. `cnt` 数组要开到 n + 2（访问 `cnt[v+1]`，v 最大等于 n）。
2. 别每步重新对整个数组求和（O(n^2) 超时）——只更新两项。
3. 总和可能**中途变小**（新牌把两个顺子并成一个），别写成只增不减的累加。
4. 输出 n 个数、空格分隔，每步都要输出。
5. 暴力对拍要用**真实的最小值**：写"穷举所有划分方式"的记忆化搜索，不能拿同一个公式再写一遍（同源互拍等于没拍）。

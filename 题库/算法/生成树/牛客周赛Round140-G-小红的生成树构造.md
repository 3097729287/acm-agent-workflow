# 牛客周赛 Round 140 G - 小红的生成树构造

- **难度**：CF 1800
- **原题链接**：https://ac.nowcoder.com/acm/contest/132940/G
- **题解位置**：`题解\牛客周赛\Round140\Round140题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\生成树\`
- **数据结构与算法**：生成树（结构刻画 + 缩点 + BFS 建树）+ 并查集
- **具体知识点**：子图诱导连通块条件；判定与构造共用一套 DSU；缩点图连通性证明；跨组边 BFS 取生成树

## 题意（精简）

n 点 m 边无向连通图，每点标记 A/B/C/D。求一棵生成树，使得：
每个 A 点都有一条**不经过任何 C/D 点**的路径通到某个 B 点（B→A 对称）；每个 C 点都有一条**不经过任何 A/B 点**的路径通到某个 D 点（D→C 对称）。
存在输出 Yes + n-1 条边（顺序任意），否则 No。Special Judge。

**数据范围**：2 ≤ n ≤ 2×10^5，m ≤ min(n(n-1)/2, 2×10^5)。

## 关键点（为什么用这个算法）

1. 把四条要求翻译成"诱导子图连通块"的话：令 S1 = {A,B}、S2 = {C,D}。A→B 的合法路径只踩 S1 的点，所以在生成树里 S1 的**每个连通块必须同时含 A 和 B**（S2 同理含 C 和 D）。
2. 生成树的边是原图边的子集 → 树里 S1 的块只会比 `G[S1]` 的分量**更碎**，于是只要看原图：
   **可行 ⟺ `G[S1]` 的每个连通分量里 A、B 都有，且 `G[S2]` 的每个连通分量里 C、D 都有。**
3. 充分性靠构造直接给：① 组内边取生成森林（每块 = `G[S1]`/`G[S2]` 的一个分量）；② 把块缩成点，跨组边建图 H（G 连通 ⟹ H 连通：G 里任一路径按"进出块"分段即得 H 的通路）；③ 在 H 上 BFS 取生成树。边数 n - 块数 + 块数 - 1 = n - 1，且连通 → 就是生成树；组内块划分未被跨组边影响 → 要求全满足。
4. 实现上判定与构造共用一个并查集：`mask[根]` 用位掩码记"A/C 记 1、B/D 记 2"，为 3 才合法。

## 复杂度

- 时间：O(n α(n) + m)，最大规模（n = m = 2×10^5）实测 33 ms；"全是 A/B"的极端情形 60 ms
- 空间：O(n + m)

## 踩过的坑

1. **判定写成"整张图里 A、B 都有"** → 必须看 `G[S1]` 的**分量**。官方样例 2（ACBD 链）就是反例：A、B 都在，但 A 被 C 隔开 → No。
2. **组内边 union 时把跨组边也并了** → 掩码把两组混在一起算，判定永远失效。union 前判 同组。
3. **缩点后只连一条跨组边** → 有多个块时图不连通、边数也不足 n-1；必须 BFS/DFS 连成一棵树。
4. **输出 No 之后还继续输出边**，或输出一条**原图里不存在**的边（Special Judge 会判错，本地务必写校验器）。
5. **小数据边界**：n = 2 且一个 A 一个 C → No；全 C/D（没有 A/B）时 S1 无分量、条件自动满足，答案看 S2。
6. 用 `int` 存 n, m 没问题，但邻接表和边数组要注意 m 只有 2×10^5，别开 n²。

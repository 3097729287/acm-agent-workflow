# 牛客周赛 Round 123 G - 小红出千

- **难度**：CF 1800
- **原题链接**：https://ac.nowcoder.com/acm/contest/125954/G
- **题解位置**：`题解\牛客周赛\Round123\Round123题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\双指针\`（本场新建）
- **数据结构与算法**：排序 + 双指针（滑动窗口）+ 构造方案
- **具体知识点**：把"改成顺子"转成"最多保留多少种不同数字落在一个长度 n 的窗口里"；
  `L = max(1, D[j] − n + 1)`；保留每种的第一次出现，空闲牌依次填空缺

## 题意（精简）

n 张牌，牌面 a<sub>i</sub> ≤ 10^9、可重复。每次「出千」把任意一张牌改成任意正整数，
目标是让这 n 张牌整体成为一个顺子（重排后是 x, x+1, …, x+n−1，即 n 个互不相同的连续整数）。
求最少出千次数并输出方案（每行"第 i 张 改成 x"，1 ≤ x ≤ 2×10^9）。Special Judge。

**数据范围**：n ≤ 2×10^5；a<sub>i</sub> ≤ 10^9

## 关键点（为什么用这个算法）

1. 最终是 n 个**互不相同**的连续整数 ⇒ 原样保留的牌必须数字两两不同、且都落进某个长度 n 的区间
   [L, L+n−1]。问题转成"找一个长度 n 的窗口，覆盖尽量多**种**不同的数字"，
   答案 = n − 最多覆盖种类数（同一个数字有多张也只能保留 1 张）。
2. 把出现过的数字排序去重成 `D[0..m−1]`，用同向双指针求 D[j] − D[i] ≤ n−1 的最宽窗口：
   j 右移，装不下就把 i 右移（i 只增不减，因为 D 升序、j 变大只会更装不下）→ O(m)。
3. 方案：取 `L = max(1, D[j] − n + 1)`（右端往回退 n−1，但不小于 1），
   保留窗口里每个数字**第一次出现**的那张牌，剩下的牌依次填进 [L, L+n−1] 中空缺的数字——
   空闲牌数与空缺数必然相等。

## 复杂度

- 时间：O(n log n)（排序去重）+ O(n)（双指针与生成方案）
- 空间：O(n)

## 踩过的坑

1. 数的是"不同数字的种数"，不是牌的张数 → 必须先排序去重再双指针（比如 5 5 5 只能保留 1 张）。
2. L 必须 max(1, …)：窗口右端回退时可能算到 0 或负数，而目标顺子必须全是正整数。
3. 新数字可到 2×10^9，L + n − 1 要用 `long long`。
4. 排序时值相同的牌要**按下标升序**排，这样"每个数字第一次出现的那张"才是输入里最靠前的那张，
   方案才稳定可复现。
5. Special Judge：方案不唯一，牛客"自测运行"可能报错 → 要自己验证"改完之后是 n 个互不相同的连续整数"。
6. 暴力对拍不能直接比输出（方案不唯一）→ 写检查器逐条验证方案合法性，再用**枚举起点 L** 的暴力比最优值。

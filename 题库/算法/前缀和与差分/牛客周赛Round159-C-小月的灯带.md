# 牛客周赛 Round 159 C - 小月的灯带

- **难度**：CF 900
- **原题链接**：https://ac.nowcoder.com/acm/contest/139660/C
- **题解位置**：`题解\牛客周赛\Round159\Round159题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\前缀和与差分\`
- **数据结构与算法**：前缀和与差分 + 二分查找
- **具体知识点**：前缀和定位第 p 盏灯落在第几段，再二分上界；前缀和必须开 `long long`（a<sub>i</sub> ≤ 10^18）

## 题意（精简）

灯带被切成 m 段，第 i 段有 a<sub>i</sub> 盏灯，段内状态全同、相邻段状态相反，第 1 段的状态由输入给定为 b。
q 次询问，每次给一个 p：输出第 p 盏灯的状态、它在第几段、它是这一段的第几盏。
定位的依据是"第 i 段占据区间 `(pre[i-1], pre[i]]`"，而不是把灯带真的铺开。

**数据范围**：m、q 到 2×10^5 量级；a<sub>i</sub> 最大 10^18，总和不超过 10^18。

## 关键点（为什么用这个算法）

1. 信号：段是连续区间，且每个 a<sub>i</sub> ≥ 1，所以前缀和 pre[i] = a<sub>1</sub> + ... + a<sub>i</sub> 单调递增——单调性天生适合二分。
2. 朴素做法把灯带铺成长度 Σa<sub>i</sub> 的数组：Σa<sub>i</sub> 最大 10^18，数组开不出来，时间也炸，所以必须在不铺开的前提下定位。
3. 正解：段号 = 第一个满足 pre[i] ≥ p 的 i（一次 `lower_bound`）；段内编号 = `p - pre[i-1]`；状态 = b 与 (i-1) 的奇偶性异或（相邻段必须相反，第 i 段相当于翻了 i-1 次）。

## 复杂度

- 时间：预处理 O(m)，每次询问二分 O(log m)，总计 O(m + qlog m)；log2(2×10^5) ≈ 18，q = 2×10^5 时约 3.6×10^6 次比较（实测 0.095 s）
- 空间：O(m)（前缀和数组）

## 踩过的坑

1. 前缀和用 `int` → a<sub>i</sub> 到 10^18 直接溢出。危险在于**样例数值都很小、本地跑样例毫无异常，只有提交才炸** → 前缀和一律写 `long long`。
2. 二分写成找 `pre[i] > p` → p 正好是某段最后一盏灯时会定位到下一段；要找的是 pre[i] ≥ p。
3. 段内编号写成 `p - pre[i]` → 负数；正确是 `p - pre[i-1]`（前面所有段的灯都排在它前面）。
4. 别真去展开灯带（10^18 盏灯），这是本题的存在意义。

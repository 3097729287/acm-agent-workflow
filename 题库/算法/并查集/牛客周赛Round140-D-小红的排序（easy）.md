# 牛客周赛 Round 140 D - 小红的排序（easy）

- **难度**：CF 1300
- **原题链接**：https://ac.nowcoder.com/acm/contest/132940/D
- **题解位置**：`题解\牛客周赛\Round140\Round140题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\并查集\`
- **数据结构与算法**：并查集（位置图连通性）
- **具体知识点**：把"交换数组里的值"翻译成"位置图的边"，连通块内可任意重排（对换生成对称群）；判定每个值 v 与它当前所在的位置同块

## 题意（精简）

给一个 1..n 的排列 p 和两个正整数 x、y（本题保证 x < y ≤ ⌊n/2⌋）。
每次操作选一个下标 i，可以交换 p<sub>i</sub> 与 p<sub>i+x</sub>（要求 i+x ≤ n）或 p<sub>i</sub> 与 p<sub>i+y</sub>（要求 i+y ≤ n）。
问能否通过若干次操作把排列变成升序 [1, 2, …, n]：能输出 Yes，否则 No。多组测试数据。

**数据范围**：T ≤ 2×10^4，4 ≤ n ≤ 2×10^5，单个测试文件 Σn ≤ 2×10^5。

## 关键点（为什么用这个算法）

1. 关键转换：p<sub>i</sub> 与 p<sub>i+x</sub> 交换，本质是**位置 i 与位置 i+x 对调**——能不能换只看位置关系，与那两个位置上装的是几无关。
2. 把位置 1..n 当点，合法的 (i, i+x)、(i, i+y) 连边（**注意要满足 i+x ≤ n / i+y ≤ n**）。同一连通块内，对换能生成任意置换（对换生成对称群）。
3. 于是判定：对每个值 v，"v 当前所在的位置"与"位置 v"必须同块。（因为 p 是排列，"值 v 在哪"与"位置 v 上是哪个值"是同一对配对关系，`find(v) == find(p[v])` 与 `find(pos[v]) == find(v)` 等价。）
4. 图**可以不连通**：n=8, x=2, y=4 时步长都是偶数，奇数位 {1,3,5,7} 与偶数位 {2,4,6,8} 分成两块——官方样例 1 的第二组就是这个结构，答案是 No。

## 复杂度

- 时间：O(Σn · α(n))，Σn = 2×10^5 时约 2×10^5 次并查集操作（实测 23 ms）
- 空间：O(n)

## 踩过的坑

1. **忘了 i + x ≤ n**：x 可以接近 n，那时只有 i = 1 能换；直接 1..n 全连边会造出假边，答案偏 Yes。
2. **判断方向写反**：要判的是"值 v 现在待的位置"与"位置 v"同块；用 `pos[值] = 下标` 时最容易抄反，反了样例 1 的第二组（No）会变 Yes。
3. **`find` 写递归**：本 DSU 只有路径减半、没有按秩合并，n = 2×10^5 时树可能很深，递归有爆栈风险（同类记录：递归 dfs 在 2×10^5 的链上直接 0xC00000FD）。**写迭代版**。
4. **多组数据不清空**：T 到 2×10^4，每组按当组 n 重建 `vector`；共用全局数组只清 1..n 会在 n 变小时残留旧数据。
5. **每组重开 O(2×10^5) 的数组清零**：T = 2×10^4 时会变成 4×10^9 次操作，直接超时。按需建 vector<int>(n+1)。

# 牛客周赛 Round 124 D - 云栖山涧听松

- **难度**：CF 1300
- **原题链接**：https://ac.nowcoder.com/acm/contest/126120/D
- **题解位置**：`题解\牛客周赛\Round124\Round124题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\图论\`
- **数据结构与算法**：图论（桥 / 无桥图）+ 度数统计
- **具体知识点**：删边连通 ⟺ 无桥；树上加边把路径上的边"救"进环；最少加边 = ⌈叶子数 / 2⌉

## 题意（精简）

给一棵 n 个点的树，最少加多少条无向边（可以重边、可以自环），使得加完之后**删掉任意一条边，图仍然连通**。只要输出这个最少数目。

**数据范围**：n ≤ 2 × 10<sup>5</sup>；限时 1 秒，空间 256 MB。

## 关键点（为什么用这个算法）

1. 「删掉任意一条边仍连通」⟺ 图里**没有桥**（每条边都在某个环上）。树有 n − 1 条边、全是桥。
2. 朴素做法是搜"加边集合"，是指数级，n 上到 2 × 10<sup>5</sup> 完全不可能。
3. 关键观察一（下界）：叶子 v 的度数是 1，它唯一那条边是桥，要让这条边不是桥就必须给 v 添一条新边 —— 因为树上别的边动不了。一条新边 (u, v) 最多"救"两个叶子（u、v 各一个；自环只救一个）。所以至少要 ⌈叶子数 / 2⌉ 条。
4. 关键观察二（上界）：把叶子按 DFS 序排成一圈，第 i 个叶子连第 i + ⌈leaf/2⌉ 个叶子，恰好 ⌈leaf/2⌉ 条就能让所有叶子得救、且每条树边都进某个环。
5. 于是答案 = ⌈叶子数 / 2⌉，读边时数度数即可，连图都不用建。

## 复杂度

- 时间：O(n)（读边 + 数度数），实跑极限 0.029 s
- 空间：O(n)（度数数组）

## 踩过的坑

1. **叶子是"度数为 1"**，不是"没有儿子"：n = 2 时两个点度数都是 1，答案是 1（两点之间再加一条重边）——按"根节点没有儿子就是叶子"写会得到 0。
2. **整数除法就是上取整**：(leaf + 1) / 2，别写成 ceil(leaf / 2.0) 再转（浮点没必要，还容易写错类型）。
3. **这题不适合用随机对拍**：加边方案是集合级搜索，暴力在 n ≥ 8 就跑不动。替代验证是**枚举 n ≤ 7 的全部标号树**（Prüfer 序列）× 枚举加边多重集 × 逐条删边重算连通性，实跑 0 处不一致（脚本 `题解\_work\nk126120\brute_D.py`）。题解里如实写成"未做随机对拍"，但把这项穷举验证写清楚。

# 牛客周赛 Round 143 C - 小红的因子幂和

- **难度**：CF 1300
- **原题链接**：https://ac.nowcoder.com/acm/contest/134529/C
- **题解位置**：`题解\牛客周赛\Round143\Round143题解.md`（整场题解，含完整推导）
- **归档文件夹**：`算法\素数\`
- **数据结构与算法**：素数 + DFS 枚举因子 + 快速幂
- **具体知识点**：质因数分解 v = x·y、枚举 v 的全部因子、快速幂算 d^d mod p

## 题意（精简）

给 x, y，记 v = x·y，求 v 的所有因子 d 的 d^d 之和对 10^9+7 取模。
输入两个整数，输出一行答案；因子 d 本身可能是 10^9+7 的倍数。

**数据范围**：1 ≤ x, y ≤ 10^9+7，故 v 最大约 10^18；原文实测 τ(v) 最多 36855（取 x = y = 735134400 时）。

## 关键点（为什么用这个算法）

1. 信号：求和对象是「v 的全部因子」，而 v 只以 x·y 的形式给出 —— 因子结构完全由质因数分解决定，分解是唯一的入口。
2. 朴素做法 `for (d = 1; d <= v; d++) if (v % d == 0)`：v 能到 10^18 量级，这个循环不可能跑完。
3. 正解的关键观察：v = p1^e1 · p2^e2 · … · pk^ek 时，每个因子都能唯一写成 p1^a1 · … · pk^ak（0 ≤ ai ≤ ei），枚举量只有因子个数 τ(v)。做法是：把 x、y 各试除到 √（约 31623）分解并把同底数的指数相加，DFS 按每个指数从 0 取到 ei 生成因子，每个因子做一次快速幂累加。

## 复杂度

- 时间：分解 O(√max(x,y)) ≈ 3×10^4；枚举因子 O(τ(v)) 个，每个一次快速幂 O(log v)，τ(v) 取 3.7 万时约 2×10^6 次运算（实测 8 ms）
- 空间：O(k)，k 为不同质因子个数；只需存分解结果和 DFS 栈深度，不必存下所有因子

## 踩过的坑

1. **指数顺手也取了模** → d^d 被算成 d^(d mod p)，答案错。为什么：d^d 的底数和指数都是 d，但只有**底数**要 d % MOD，指数 d 不能取模（d ≤ 10^18 放得进 `long long`）。下次：快速幂只让底数进模。
2. **以为底数为 0 要特判** → 不用：如 x = y = 10^9+7 时 v = MOD^2，因子 MOD、MOD^2 取模后都是 0，pw(cur % MOD, cur) 天然给出贡献 0（底数 0、指数 ≥ 1）。
3. **DFS 里用 `int` 拼因子** → 中间乘积可达 v ≤ 10^18，直接爆；必须用 unsigned long long。
4. **担心试除条件 p * p <= x 溢出** → 不必：p ≤ 31623 时 p*p 只有 10^9 量级，`long long` 安全。
